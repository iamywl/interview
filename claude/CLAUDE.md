## 2. 디렉토리 구조 — "주제 우선 → 연도 하위" (확정·핵심)
- **주제별로 디렉토리를 만들고, 그 디렉토리 안에 연도별 파일**을 둔다.
- 연도 범위는 **2021 ~ 2026 (6년치)**. 파일명은 `<연도>.md`.

```
claude/research/
  README.md                     # 16개 주제 전체 인덱스
  genai/
    README.md                   # 이 주제의 연도별 인덱스
    2021.md  2022.md  2023.md  2024.md  2025.md  2026.md
  semiconductor/
    README.md
    2021.md … 2026.md
  …(아래 16개 주제 디렉토리 각각 동일하게)
```

- 즉 산출물 경로 형식은 **`claude/research/<slug>/<연도>.md`**
  (예: `claude/research/genai/2024.md`, `claude/research/robotics/2025.md`).
- 주제별 `README.md` = 그 주제의 연도별 자료 인덱스.
- 루트 `claude/research/README.md` = 16개 주제 전체 인덱스와 사용법.

## 4. 각 연도 문서 형식 (`<slug>/<연도>.md` 목차 고정) — 강화판(v2)
각 연도 파일은 "그해 그 주제"의 뉴스 + **개념설명 + 모범답안**을 담은 PT면접 공부자료다.
아래 10개 목차를 그대로 사용한다. (기존 8목차 v1에서 **4번 신기술 개념설명**과 **9번 모범답안**을 신설·강화)

```
## <연도> · <주제 라벨>

### 1. 한눈에 보기
- 그해 그 주제의 핵심을 3~4줄로 압축.

### 2. 그해 핵심 트렌드
- 불릿 4~6개.

### 3. 대표 뉴스·사건
- 불릿 6개 이상. 각 항목 끝에 (매체·날짜·마크다운 링크) 출처 필수.

### 4. 신기술 개념설명 ★신설 (이 해 공부의 핵심)
- 그해 처음 등장했거나 부상한 핵심 기술·용어 2~3개를 고른다.
- 각 기술마다 네 가지를 직접 설명한다(비유 금지, 비전공 면접관도 이해하게):
  (1) 한 줄 정의  (2) 왜 나왔나(기존 방식의 한계)  (3) 어떻게 동작하나(원리)  (4) 무엇이 달라지나(의의·한계)

### 5. 핵심 기업·제품·기술 키워드

### 6. 시장 수치·전망 (미확정·전망치는 "전망/추정" 표기)

### 7. 전년 대비 변화점 (새로 뜬 것 / 식은 것)

### 8. PT 발표 주제 후보
- 2~3개. 각 항목: 제목 + 한 줄 메시지 + 발표 3단 구조(문제 → 근거 → 제언).

### 9. 예상 질문 + 모범답안 ★강화 (실제 말할 대본 수준)
- 4개 이상. 각 질문에 면접장에서 그대로 말할 수 있는 모범답안(3~6문장).
- 일부 답변에 지원자 경험(컨테이너 보안·시스템콜 동적관측 이상탐지·Linux 커널)을 자연스럽게 연계.

### 10. 참고문헌 (본문에서 인용한 출처 링크 목록)
```

### 4-1. 주제별 학습문서 `<slug>/STUDY.md` ★신설
각 주제 디렉토리에 6년치를 종합한 **메인 공부자료** `STUDY.md`를 둔다. 목차:

```
# <주제 라벨> — SSAFY PT면접 학습문서

## A. 왜 이 주제가 중요한가 (3줄)
## B. 반드시 아는 핵심 개념 사전 — 면접 빈출 용어·기술을 정의/원리/의의로 설명
## C. 연도별 흐름 한눈에 (2021 → 2026, 각 한 줄 + 연도파일 링크)
## D. PT 발표 주제 추천 (3~5개, 각: 제목 / 핵심 메시지 / 발표 3단 구조)
## E. 모범답안집 (예상질문 8개 이상 + 면접장 대본형 모범답안)
## F. 지원자 경험 연계 포인트 (컨테이너 보안·시스템콜 이상탐지·커널을 이 주제와 잇는 멘트)
## G. 빠른 암기 카드 (핵심 수치·날짜·키워드 표)
## H. 참고 (연도파일 링크 + 주요 출처)
```

## 5. 근거 · 참고문헌 규칙 (필수·강화)
- 모든 연도 문서는 **실제 뉴스 기사 / 공식 발표를 근거**로 작성한다. 근거 없는 서술 금지.
- `### 2. 대표 뉴스·사건`의 **각 항목마다 출처를 명시**한다:
  **매체명 · 날짜 · 마크다운 링크** 형식. 예: `([연합뉴스, 2024-03-19](URL))`.
- 출처 우선순위: **공식 출처**(기업 뉴스룸·정부/공공·표준 문서·위키피디아·주요 언론) 우선.
- 수치·날짜는 **교차 확인**하고, 미확정·전망치는 본문에 **"전망" 또는 "추정"**으로 표기한다.
- 문서 말미 `### 8. 참고문헌`에 본문에서 쓴 링크를 매체·날짜와 함께 목록으로 정리한다.

## 6. 조사 방법
- **주제 × 연도** 셀(최대 16×6 = 96개)을 **독립 에이전트로 병렬 조사**한다.
- 조사에는 **웹 검색을 적극 활용**(WebSearch/WebFetch)해 실제 기사·발표를 찾아 근거로 인용한다.
- 지원자 배경(컨테이너 보안·시스템 콜 동적 관측 기반 이상탐지·Linux 커널 이해,
  풀스택·코딩테스트로 확장하려는 SSAFY 지원자)을 꼬리질문 답변에 자연스럽게 녹인다.
