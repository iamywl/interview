# SSAFY PT면접 대비 자료

SSAFY(삼성 청년 SW·AI 아카데미) **PT면접(발표면접)** 준비 자료 모음. 주제를 발표하고 꼬리질문에 답하는 형식에 대비해, **IT 시사**와 **CS 기초**를 주제별로 정리했다. 모든 문서는 한국어·사실 중심이며 각 문서 끝에 **참고문헌(출처 링크)**을 포함한다.

작업 지침은 [CLAUDE.md](CLAUDE.md) 참조. 조사는 주제별로 **병렬**로 진행했고 날짜·수치는 웹 검색으로 교차 확인했다.

## 추천 학습 순서
1. **00_PT면접_가이드**로 발표 구성·전달 방식을 먼저 익힌다.
2. 본인 강점 주제부터: CS 지망이면 `cs_기초/`, 시사 발표 대비면 `it_시사/00_IT시사_PT발표주제`.
3. 각 주제는 "발표 주제 후보 → 핵심 개념 → 예상 질문" 순으로 보고, 답변을 **소리 내어** 연습한다.
4. **06 통합 타임라인**으로 IT 5년 흐름을 한 번에 정리한다.

## 면접 직전 확인
- SSAFY 취업률·기수·교육과정 수치는 갱신되므로 [ssafy.com](https://www.ssafy.com)과 [삼성전자 사회공헌](https://csr.samsung.com/ko/program/samsung-sw-academy-for-youth)에서 최신값 확인.
- 최근 1~2주 IT 뉴스 1건을 추가로 챙기면 시의성에서 유리하다.
- 일부 2026년 수치는 보도 기준 전망·추정치이므로 "전망"으로 표현.
