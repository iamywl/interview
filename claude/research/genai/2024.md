## 2024 · 생성형 AI · LLM · 파운데이션 모델

### 1. 그해 핵심 트렌드
- 멀티모달이 '실시간·통합'으로 진화했다. GPT-4o가 텍스트·음성·이미지를 단일 모델로 입출력하며 사람 수준의 응답 속도를 보였고, 텍스트-투-비디오(Sora)가 등장하며 생성 영역이 영상으로 넓어졌다.
- 프런티어 모델 경쟁이 다강 구도로 굳어졌다. OpenAI(GPT-4o), 앤트로픽(Claude 3), 구글(Gemini), 메타(Llama 3)가 벤치마크에서 엎치락뒤치락하며 격차가 좁혀졌다.
- 비용·효율 경쟁이 본격화됐다. API 가격 인하, 소형 고성능 모델(GPT-4o mini, Llama 3 8B) 출시로 기업 도입 문턱이 낮아졌다.
- AI의 과학적 기여가 노벨상으로 공인됐다. 신경망·단백질 구조 예측 연구가 물리·화학상을 받으며 딥러닝의 기반 가치가 재평가됐다.

### 2. 대표 뉴스·사건
- OpenAI가 2월 15일 텍스트-투-비디오 모델 'Sora'를 프리뷰로 공개했다. 최대 1분 길이의 고해상도 영상을 한 번에 생성하는 확산 모델로, 초기에는 레드팀·창작자 일부에게만 제한 공개됐다. ([Axios, 2024-02-15](https://www.axios.com/2024/02/15/openai-text-to-video-sora))
- 앤트로픽이 3월 4일 'Claude 3'(Opus·Sonnet·Haiku) 시리즈를 발표했다. 최상위 Opus가 다수 학술 벤치마크에서 GPT-4·Gemini Ultra를 앞섰고, 약 20만 토큰 컨텍스트 윈도우를 제공했다. ([VentureBeat, 2024-03-04](https://venturebeat.com/ai/anthropic-unveils-claude-3-claims-new-standard-for-intelligence))
- 메타가 4월 18일 'Llama 3'(8B·70B)를 공개했다. 15조 토큰으로 학습돼 Llama 2 대비 약 7배 큰 데이터셋을 사용했으며, 상업적 이용이 가능한 개방형 라이선스로 배포됐다. ([Meta AI, 2024-04-18](https://ai.meta.com/blog/meta-llama-3/))
- OpenAI가 5월 13일 통합 멀티모달 플래그십 'GPT-4o'(omni)를 공개했다. 텍스트·오디오·이미지를 입력받고 평균 약 320ms로 음성에 응답하며, API 가격은 GPT-4 Turbo 대비 절반 수준이었다. ([TechCrunch, 2024-05-13](https://techcrunch.com/2024/05/13/openais-newest-model-is-gpt-4o/))
- 2024년 노벨 물리학상이 인공신경망 기반 머신러닝 연구의 홉필드·힌턴에게, 화학상이 단백질 구조 예측 AI(AlphaFold2)의 하사비스·점퍼와 단백질 설계의 베이커에게 수여됐다. ([NobelPrize.org, 2024-10-08](https://www.nobelprize.org/prizes/physics/2024/press-release/))

### 3. 핵심 기업·제품·기술 키워드
- 기업: OpenAI, 앤트로픽, 구글(딥마인드), 메타, 마이크로소프트, 미스트랄(Mistral), 네이버
- 제품·모델: GPT-4o, GPT-4o mini, Sora, Claude 3(Opus/Sonnet/Haiku), Llama 3, Gemini 1.5, AlphaFold
- 기술 키워드: 통합 멀티모달, 텍스트-투-비디오, 긴 컨텍스트 윈도우, 소형 고성능 모델(SLM), 추론 비용 절감, 음성 대화

### 4. 시장 수치·전망 (전망/추정 표기)
- GPT-4o: 음성 입력에 평균 약 320ms 응답, API 가격 GPT-4 Turbo 대비 약 50% 저렴(OpenAI 발표).
- Claude 3 Opus: 약 20만 토큰 컨텍스트 윈도우(Anthropic 발표).
- Llama 3: 약 15조 토큰 학습, Llama 2 대비 약 7배 데이터셋(Meta 발표).
- Sora: 최대 1분 길이 영상 생성, 2024년 시점 리서치 단계(연내 일반 제품 미탑재).

### 5. 전년 대비 변화점 (새로 뜬 것 / 식은 것)
- 새로 뜬 것: 실시간 음성·통합 멀티모달, 텍스트-투-비디오, 소형 고성능 모델, API 가격 인하 경쟁, AI의 노벨상 공인.
- 식은 것: 단순 텍스트 챗봇 경쟁 위주 서사. GPT-4 단독 우위가 Claude 3·Gemini·Llama 3의 추격으로 희석.

### 6. PT 발표 주제 후보
- "실시간 멀티모달, GPT-4o가 연 것" — 음성·이미지 통합 모델이 인간-AI 상호작용을 어떻게 바꾸는지 설명.
- "텍스트로 영상을 만든다: Sora와 그 파장" — 영상 생성의 가능성과 딥페이크·저작권 리스크를 정리.
- "작지만 강한 모델의 시대: SLM" — 소형 고성능 모델과 온디바이스 추론이 기업 도입을 어떻게 가속하는지 논의.

### 7. 예상 꼬리질문 + 답변 포인트
- Q: 통합 멀티모달 모델이 기존 파이프라인 대비 갖는 보안적 함의는? → A: 음성·이미지·텍스트가 한 모델로 들어오면 각 입력 경로가 모두 잠재적 주입 공격면이 된다. 입력 경로별로 동적 검증·관측을 두어야 하며, 이는 시스템 콜 단위로 동작을 관측해 이상을 잡는 접근과 같은 발상이다.
- Q: 소형 모델(SLM)이 온디바이스에서 돌아갈 때 생기는 문제는? → A: 모델·가중치가 단말에 내려가면 추출·역공학 위험이 커진다. 컨테이너처럼 모델 실행 환경을 격리하고 런타임을 관측해 비정상 접근을 탐지하는 통제가 필요하다.
- Q: AI가 노벨상을 받은 의미를 어떻게 보나? → A: 딥러닝이 기초과학의 도구로 인정받았다는 신호다. 다만 AlphaFold 같은 성과도 예측 결과를 실험으로 검증해야 하듯, 모델 출력은 실제 관측·검증과 결합돼야 신뢰할 수 있다.
