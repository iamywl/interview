## 2021 · 생성형 AI · LLM · 파운데이션 모델

### 1. 그해 핵심 트렌드
- 2020년 공개된 GPT-3(1,750억 매개변수)의 충격이 산업 전반으로 확산된 해다. 글로벌 빅테크와 연구소가 경쟁적으로 초거대 언어모델을 발표하면서 "파라미터 규모 경쟁"이 본격화됐다.
- 텍스트 외 영역으로 확장이 시작됐다. 텍스트로 이미지를 생성하는 DALL·E, 코드를 생성하는 GitHub Copilot이 등장하며 생성형 AI의 적용 범위가 넓어졌다.
- 학계에서 "파운데이션 모델(foundation model)"이라는 용어가 정립됐다. 스탠퍼드가 광범위한 데이터로 사전학습 후 다양한 다운스트림 작업에 적응시키는 모델 패러다임을 정의했다.
- 한국에서는 초거대 AI 개발 경쟁(네이버 하이퍼클로바, 카카오 KoGPT 등)이 시작되는 동시에, '이루다' 사건으로 AI 윤리·개인정보 문제가 사회적 화두가 됐다.

### 2. 대표 뉴스·사건
- OpenAI가 텍스트 설명으로 이미지를 생성하는 신경망 'DALL·E'를 공개했다. GPT-3 기반 120억 매개변수 모델로, 자연어 캡션을 다양한 개념의 이미지로 변환한다. ([OpenAI, 2021-01-05](https://openai.com/index/dall-e/))
- 스캐터랩의 AI 챗봇 '이루다'가 개인정보 유출·혐오 발언 논란으로 정식 출시 약 3주 만인 1월 12일 서비스를 잠정 중단했다. 이후 개인정보보호위원회가 과징금·과태료 약 1억 330만 원을 부과했다. ([서울신문, 2021-01-12](https://www.seoul.co.kr/news/society/2021/01/12/20210112009034))
- 구글 브레인이 1.6조 매개변수의 'Switch Transformer'를 발표했다. Mixture of Experts(MoE) 라우팅을 단순화해 GPT-3의 약 6배 규모를 상수 수준의 연산 비용으로 학습할 수 있음을 보였다. ([Synced, 2021-01-14](https://syncedreview.com/2021/01/14/google-brains-switch-transformer-language-model-packs-1-6-trillion-parameters/))
- GitHub가 OpenAI Codex 기반의 'GitHub Copilot'을 6월 29일 기술 프리뷰로 공개했다. 작성 중인 코드 맥락에서 줄·함수 단위 제안을 제공하는 AI 페어 프로그래머로, 생성형 AI의 개발 도구 적용을 알렸다. ([GitHub Blog, 2021-06-29](https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/))
- 스탠퍼드 CRFM이 100명 이상이 참여한 200쪽 분량 보고서 'On the Opportunities and Risks of Foundation Models'를 발표하며 '파운데이션 모델'이라는 용어를 정립했다. ([arXiv, 2021-08-16](https://arxiv.org/abs/2108.07258))
- 카카오브레인이 한국어 특화 초거대 언어모델 'KoGPT'를 GitHub에 공개했다. 60억 매개변수와 2,000억 토큰의 한국어 데이터로 학습됐다. ([카카오, 2021-11-15](https://www.kakaocorp.com/page/detail/9600))

### 3. 핵심 기업·제품·기술 키워드
- 기업: OpenAI, 구글(Google Brain), GitHub/마이크로소프트, 네이버, 카카오브레인, 화웨이
- 제품·모델: GPT-3, DALL·E, GitHub Copilot, Codex, Switch Transformer, KoGPT, 하이퍼클로바, 판구 알파
- 기술 키워드: 파운데이션 모델, 초거대 AI, Mixture of Experts(MoE), 텍스트-투-이미지, 사전학습-적응(pretrain-adapt), AI 윤리·개인정보

### 4. 시장 수치·전망 (전망/추정 표기)
- Switch Transformer는 1.6조 매개변수로, GPT-3(1,750억)의 약 6배 규모(공식 발표 수치).
- GitHub Copilot은 기술 프리뷰 단계로, 정식 유료 출시는 2022년으로 예고됨.
- KoGPT는 60억 매개변수·2,000억 토큰 한국어 데이터 학습(카카오 발표 수치).

### 5. 전년 대비 변화점 (새로 뜬 것 / 식은 것)
- 새로 뜬 것: 텍스트-투-이미지(DALL·E), 코드 생성(Copilot)으로의 멀티모달·도구 확장. '파운데이션 모델' 개념 정립. 한국형 초거대 AI 경쟁 점화.
- 식은 것: "단일 거대 밀집(dense) 모델만이 답"이라는 인식이 약화되고, MoE 같은 희소(sparse) 효율화 접근이 부상.

### 6. PT 발표 주제 후보
- "파운데이션 모델의 탄생: 왜 2021년인가" — 하나의 사전학습 모델이 여러 작업에 적응하는 패러다임 전환을 설명.
- "이루다 사건이 남긴 것: 생성형 AI와 개인정보" — 학습 데이터 수집·정제와 프라이버시 규제의 필요성을 정리.
- "코드를 쓰는 AI, Copilot의 의미" — 개발 생산성 변화와 라이선스·보안 쟁점을 함께 제시.

### 7. 예상 꼬리질문 + 답변 포인트
- Q: Mixture of Experts가 일반 모델과 무엇이 다른가? → A: 전체 파라미터 중 입력마다 일부 전문가(expert) 레이어만 활성화해 연산 비용을 억제하는 희소 구조다. 시스템 콜 동적 관측에서 전체 호출을 다 보지 않고 의미 있는 경로만 골라 분석하는 방식과 유사하게, 자원 대비 효율을 높이는 선택적 활성화가 핵심이다.
- Q: 이루다 사건의 기술적 원인은? → A: 동의 범위를 벗어난 카카오톡 대화 데이터를 학습에 사용했고, 개인정보 비식별화(정제)가 부족했다. 모델이 학습 데이터를 그대로 노출(memorization)할 수 있다는 점이 위험이다.
- Q: Copilot 같은 코드 생성 도구의 보안 리스크는? → A: 학습 데이터에 포함된 취약 코드 패턴을 그대로 제안하거나 라이선스 위반 코드를 출력할 수 있다. 컨테이너·런타임 보안 관점에서 보면, 생성된 코드를 그대로 배포하기 전 정적·동적 검증을 거치는 파이프라인이 필요하다고 본다.
