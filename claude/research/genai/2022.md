## 2022 · 생성형 AI · LLM · 파운데이션 모델

### 1. 한눈에 보기
2022년은 생성형 AI가 대중화의 원년이 된 해입니다. DALL·E 2, Stable Diffusion 같은 이미지 생성 모델이 상상력을 현실로 만들었고, 연말에 등장한 ChatGPT는 인류와 기계의 소통 방식을 완전히 바꾸며 '생성형 AI 시대'의 개막을 알렸습니다. 이 과정에서 초대규모 모델 경쟁과 오픈소스 생태계의 약진이 동시에 일어났고, AI 윤리와 신뢰성 문제가 핵심 화두로 떠올랐습니다.

### 2. 그해 핵심 트렌드
- **생성형 AI의 대중화:** DALL·E 2, Midjourney, Stable Diffusion의 연이은 출시로, 전문가가 아니어도 자연어 명령만으로 고품질 이미지를 생성하는 시대가 열렸습니다.
- **대화형 LLM의 등장과 폭발적 확산:** 11월 말, ChatGPT가 무료 리서치 프리뷰로 공개되며 직관적인 채팅 인터페이스를 통해 누구나 LLM의 능력을 체험할 수 있게 되었습니다. 출시 5일 만에 사용자 100만 명을 돌파하며 역사상 가장 빠르게 성장한 서비스가 되었습니다.
- **오픈소스 생태계의 부상:** Stability AI가 모델 가중치를 완전히 공개하고, 메타가 연구용으로 OPT-175B를 공개하면서, 누구나 강력한 생성 AI 모델을 직접 실행하고 수정할 수 있는 길이 열렸습니다. 이는 빅테크의 폐쇄적 API 모델에 대한 강력한 대안으로 부상했습니다.
- **초거대 모델 스케일 경쟁 지속:** 구글이 5400억 파라미터의 PaLM을 발표하는 등, 모델의 크기를 키워 성능을 높이려는 경쟁은 여전히 치열하게 이어졌습니다.
- **RLHF(인간 피드백 강화학습)의 중요성 대두:** ChatGPT의 놀라운 대화 품질과 안전성은 RLHF 기술을 통해 인간의 선호도와 가치에 맞게 모델을 '정렬(Alignment)'시킨 결과로, LLM 개발의 핵심 방법론으로 자리 잡았습니다.
- **AI 윤리 및 안전성 쟁점의 폭발적 부각:** AI가 생성한 그림이 미술 공모전에서 우승하고, AI가 자신있게 가짜 정보를 생성하는 등 AI의 능력과 함께 그 책임과 위험에 대한 사회적 논의가 본격적으로 수면 위로 떠올랐습니다.

- **구글, 5400억 파라미터 PaLM 발표:** Pathways Language Model (PaLM)은 TPU v4 6144칩으로 7800억 토큰을 학습하여 29개 벤치마크 중 28개에서 당시 최고 성능을 기록하며 대규모 언어 모델 스케일 경쟁을 주도했습니다. ### 4. 신기술 개념설명
#### (1) 잠재 확산 모델 (Latent Diffusion Model)
- **한 줄 정의:** 이미지를 고차원 픽셀 공간이 아닌, 핵심 특징만 압축한 저차원 '잠재 공간'에서 노이즈를 제거해 고품질 이미지를 생성하는 기술입니다.
- **왜 나왔나:** 기존 확산 모델은 고해상도 픽셀 공간 전체에서 노이즈 제거 연산을 수행해야 해서 엄청난 계산 자원을 필요로 했습니다. 일반적인 컴퓨터에서는 사실상 실행이 불가능해, 이미지 생성의 문턱을 낮추기 위해 더 효율적인 방법이 필요했습니다.
- **어떻게 동작하나:** 먼저, 오토인코더(Autoencoder)를 이용해 원본 이미지를 훨씬 작은 잠재 공간 데이터로 압축합니다. 그 후, 이 작은 잠재 공간 안에서 텍스트 프롬프트의 의미를 반영하여 노이즈를 점진적으로 제거해 나갑니다. 마지막으로, 노이즈가 제거된 잠재 공간 데이터를 다시 디코더를 통해 우리가 보는 고해상도 이미지로 복원합니다. 핵심 계산이 작은 공간에서 이뤄지므로 훨씬 적은 자원으로 빠르게 작동합니다.
- **무엇이 달라지나:** 계산 효율성을 극적으로 높여 Stable Diffusion처럼 개인용 컴퓨터에서도 실행 가능한 고성능 이미지 생성 모델의 등장을 이끌었습니다. 이는 AI 기술의 대중화와 오픈소스 생태계의 폭발적 성장에 결정적인 기여를 했습니다. 다만, 여전히 복잡한 구조나 인물 표현에는 한계가 있었습니다.

#### (2) 인간 피드백 기반 강화학습 (RLHF, Reinforcement Learning from Human Feedback)
- **한 줄 정의:** 사람이 직접 AI 모델의 답변에 좋고 나쁨을 평가하고, 그 평가 데이터를 이용해 모델이 더 유용하고 안전한 답변을 하도록 '정렬'시키는 학습 기법입니다.
- **왜 나왔나:** 인터넷의 방대한 텍스트로만 학습한 LLM은 사실과 다른 말을 하거나(환각), 편향적이거나 유해한 내용을 생성할 수 있습니다. AI를 실제 서비스에 적용하려면, 기술적 성능을 넘어 인간의 가치와 의도에 부합하도록 길들이는 과정이 필수적이었습니다.
- **어떻게 동작하나:** 주로 3단계로 이뤄집니다. 1단계는 사람이 직접 작성한 모범 답변으로 모델을 학습시킵니다(지도 미세조정, SFT). 2단계에서는 모델이 생성한 여러 답변에 대해 사람이 직접 '어떤 답변이 더 나은지' 순위를 매깁니다. 이 순위 데이터를 학습시켜 '좋은 답변을 감별하는' 보상 모델(Reward Model)을 만듭니다. 마지막 3단계에서, 원래의 LLM이 이 보상 모델로부터 높은 점수를 받는 답변을 생성하도록 강화학습을 진행합니다.
- **무엇이 달라지나:** ChatGPT 성공의 일등공신으로, LLM이 단순히 똑똑한 것을 넘어 '유용하고 무해한' 대화 파트너가 될 수 있음을 증명했습니다. 기술 성능만큼이나 '정렬(Alignment)'이 중요하다는 인식을 확산시켰고, 이후 LLM 개발의 표준적인 방법론으로 자리 잡았습니다.

#### (3) 파운데이션 모델 (Foundation Model)
- **한 줄 정의:** 특정 목적이 아닌, 방대한 데이터로 사전학습되어 다양한 종류의 문제를 해결할 잠재력을 가진 범용적인 초대규모 AI 모델입니다.
- **왜 나왔나:** 과거에는 번역 AI, 요약 AI, 감정분석 AI를 각각의 데이터셋으로 별도 개발해야 했습니다. 이는 엄청난 시간과 비용 낭비였습니다. 하나의 잘 만들어진 기반 모델만 있으면, 약간의 추가 학습(미세조정)이나 간단한 명령만으로 여러 작업을 수행할 수 있어 AI 개발의 패러다임을 바꿀 필요가 있었습니다.
- **어떻게 동작하나:** 인터넷의 텍스트, 이미지 등 막대한 데이터를 기반으로 사전학습을 진행합니다. 이 과정에서 언어의 문법, 세상의 지식, 개념 간의 관계 등 일반적인 패턴을 스스로 학습해 거대한 지식 기반을 구축합니다. 이렇게 만들어진 모델은 특정 작업(Downstream Task)에 적은 데이터로 미세조정(Fine-tuning)하거나, 프롬프트 엔지니어링을 통해 즉시 활용됩니다.
- **무엇이 달라지나:** AI 개발 방식이 '개별 모델 개발'에서 '파운데이션 모델 활용'으로 전환되었습니다. 개발 효율성과 성능을 극대화했지만, 동시에 모델 하나에 대한 의존도가 높아져 기반 모델의 취약점이나 편향이 모든 응용 서비스로 전파될 수 있는 '공급망 리스크'라는 새로운 문제를 야기했습니다.

### 5. 핵심 기업·제품·기술 키워드
- **기업:** OpenAI, Stability AI, Midjourney, 구글(Google), 메타(Meta), 마이크로소프트(Microsoft - OpenAI 투자), Hugging Face, Runway ML, LAION, EleutherAI
- **제품·모델:** ChatGPT(GPT-3.5 기반), DALL·E 2, Stable Diffusion, Midjourney, LaMDA, PaLM(540B), OPT-175B, Whisper, Galactica
- **기술 키워드:** 생성형 AI(Generative AI), 대규모 언어 모델(LLM), 파운데이션 모델(Foundation Model), 잠재 확산 모델(Latent Diffusion Model), 텍스트-투-이미지(Text-to-Image), RLHF(인간 피드백 강화학습), 트랜스포머(Transformer) 아키텍처, CLIP(Contrastive Language-Image Pre-training), 프롬프트 엔지니어링(Prompt Engineering), 환각(Hallucination), 정렬(Alignment), 오픈소스 가중치 공개, OpenRAIL-M 라이선스, 미세 조정(Fine-tuning), 인컨텍스트 학습(In-context Learning).

### 6. 시장 수치·전망
- **ChatGPT 사용자 수:** 출시 5일 만에 사용자 100만 명을 돌파했습니다 (OpenAI/Sam Altman 발표). 이는 역사상 가장 빠른 소비자 앱 성장 기록으로 평가됩니다 (UBS 분석, 2023년 전망).
- **DALL·E 2 사용자 및 생성 이미지 수:** 2022년 9월 대기자 명단 폐지 시점에는 150만 명 이상의 사용자가 매일 200만 장 이상의 이미지를 생성하고 있었습니다 (OpenAI 발표).
- **Stable Diffusion 최소 VRAM 요구 사항:** 약 2.4GB VRAM을 가진 소비자용 GPU에서도 512x512 해상도 이미지 생성이 가능했습니다 (Stability AI/Wikipedia 사양).
- **PaLM 모델 규모:** 5400억(540B) 파라미터로 학습되었으며, 7800억 토큰을 사전 학습에 사용했고, 구글의 TPU v4 6144칩을 통해 훈련되었습니다 (Google Research 발표).
- **OPT-175B 모델 규모 및 효율성:** 1750억(175B) 파라미터를 가지며, GPT-3 대비 약 1/7의 탄소 발자국으로 학습되었다고 메타는 밝혔습니다 (Meta 발표).
- **Whisper 학습 데이터 규모:** 68만 시간 분량의 방대한 다국어 음성 데이터를 활용하여 학습되었으며, 기존 특화 모델 대비 오류율을 약 50% 감소시키는 성과를 보였습니다 (OpenAI 발표).

### 7. 전년 대비 변화점
- **새로 뜬 것:**
    - **생성형 AI의 대중화:** 전문가의 영역이던 생성형 AI가 ChatGPT, Stable Diffusion 등을 통해 일반 사용자에게 직접 서비스되기 시작했습니다.
    - **소비자 GPU 기반 오픈소스 모델:** 개인 컴퓨터에서도 실행 가능한 고성능 모델이 등장하며 AI 개발의 진입 장벽이 크게 낮아졌습니다.
    - **RLHF 기반 정렬(Alignment) 기술:** 모델의 성능뿐 아니라 인간의 가치와 의도에 부합하도록 만드는 '정렬'의 중요성이 RLHF의 성공으로 증명되었습니다.
    - **'환각(Hallucination)' 문제의 대두:** LLM이 그럴듯한 거짓말을 하는 문제가 널리 알려지며 신뢰성 확보가 핵심 과제로 떠올랐습니다.
- **식은 것:**
    - **단순한 '스케일업 만능주의':** 모델 크기만 키우면 된다는 생각보다, 모델을 어떻게 유용하고 안전하게 만드느냐는 '정렬'의 중요성이 더 부각되었습니다.
    - **폐쇄형 API 독점 구도:** 빅테크의 폐쇄형 API 중심 구도가 Stable Diffusion 같은 강력한 오픈소스 모델의 등장으로 균열이 가기 시작했습니다.
    - **AI '지각'에 대한 과도한 기대:** LaMDA 논란을 통해 AI가 인간 같은 의식을 가졌다는 주장은 과장된 것으로 정리되며, 보다 현실적인 논의가 시작되었습니다.

### 9. 예상 질문 + 모범답안
#### Q1. RLHF가 ChatGPT 성공에 결정적이었던 이유는 무엇이라고 생각하십니까?
네, RLHF가 결정적이었던 이유는 단순히 똑똑한 AI를 넘어 '쓸모 있고 안전한 AI'를 만들었기 때문입니다. 기존 언어 모델은 방대한 데이터를 학습해 그럴듯한 문장을 만들었지만, 사용자의 의도에 맞거나 사실에 기반한 내용인지는 보장할 수 없었습니다. RLHF는 사람이 직접 모델의 답변에 점수를 매겨 '좋은 답변'의 기준을 가르치는 방식입니다. 이를 통해 ChatGPT는 사용자의 의도를 더 잘 파악하고, 부적절한 요청은 거절하며, 모르는 것은 모른다고 인정하는 등 훨씬 더 신뢰할 수 있는 대화 상대가 될 수 있었습니다. 같은 해에 정렬 과정 없이 출시되었다가 3일 만에 서비스를 중단한 메타의 'Galactica' 모델과 비교하면, RLHF를 통한 '정렬'이 얼마나 중요한지 명확히 알 수 있습니다.

#### Q2. 오픈소스 AI 모델의 보안 및 악용 리스크를 지원자님의 경험에 비추어 어떻게 제어할 수 있을까요?
오픈소스 AI 모델의 가중치 공개는 기술 발전의 촉매제이지만, 동시에 딥페이크나 유해 콘텐츠 생성 같은 심각한 악용 리스크를 안고 있습니다. 저는 이 문제를 제가 경험했던 컨테이너 보안 문제와 유사한 관점에서 바라봅니다. 컨테이너 환경에서 출처를 알 수 없는 이미지를 그대로 사용하는 것이 위험하듯, 안전장치가 제거된 AI 모델을 통제 없이 사용하는 것은 매우 위험합니다. 따라서 기술적 통제가 필수적입니다. 제가 컨테이너의 비정상 행위를 탐지하기 위해 시스템 콜을 동적으로 관측했던 것처럼, AI 모델의 악용을 막기 위해서도 '관측과 탐지' 기반의 접근이 필요하다고 생각합니다. 예를 들어, 생성된 콘텐츠에 보이지 않는 워터마크를 삽입해 출처를 추적하고, 특정 패턴의 악의적 프롬프트 입력을 감지하거나, 모델이 생성하는 결과물을 실시간으로 분석해 유해성을 탐지하는 시스템을 구축하는 것입니다. 이처럼 모델 자체를 완벽히 통제하기 어렵다면, 모델의 '행위' 즉, 입력과 출력을 관측하고 이상 징후를 탐지하는 다층적 보안 체계가 현실적인 대안이라고 생각합니다.

#### Q3. '환각(hallucination)' 현상이 LLM의 본질적 한계라고 보십니까, 아니면 개선 가능한 문제라고 보십니까? 그 근거는 무엇입니까?
저는 환각 현상이 LLM의 작동 방식에서 비롯된 본질적 특성이지만, 충분히 '개선하고 관리할 수 있는' 문제라고 생각합니다. LLM은 사실 관계를 이해해서 답하는 것이 아니라, 학습한 데이터 안에서 통계적으로 가장 그럴듯한 단어 조합을 생성하는 '정교한 예측 기계'에 가깝기 때문에 환각은 필연적으로 발생합니다. 하지만 이를 개선할 방법은 분명히 있습니다. 2022년에 주목받은 RLHF가 대표적인 예시로, 인간의 피드백을 통해 '더 사실에 가까운' 답변에 높은 보상을 주도록 모델을 학습시켜 환각을 줄일 수 있습니다. 또한, 제가 이전에 시스템의 이상 행위를 탐지하기 위해 정상적인 시스템 콜 패턴의 기준을 정립하고, 그 기준에서 벗어나는 행위를 찾아냈던 경험처럼, LLM의 답변도 외부의 신뢰할 수 있는 데이터베이스나 검색 결과를 통해 사실 여부를 실시간으로 교차 검증하는 '검색 증강 생성(RAG)' 같은 기술로 보완할 수 있습니다. 즉, 모델의 본질적 한계를 인정하되, 그것을 보완하는 외부 시스템과의 결합을 통해 신뢰도를 높여나가는 방향으로 문제를 해결할 수 있다고 봅니다.

#### Q4. 파운데이션 모델 방식의 확산이 가져올 장점과, 지원자께서 경험한 컨테이너 기반 시스템의 '공급망 보안' 문제와 비교하여 잠재적 위험을 설명해주십시오.
파운데이션 모델의 가장 큰 장점은 AI 기술 개발의 효율성을 극대화했다는 점입니다. 하나의 잘 만들어진 모델을 기반으로 다양한 서비스들을 빠르고 저렴하게 만들 수 있게 되었습니다. 하지만 바로 그 점이 '단일 실패점(Single Point of Failure)' 또는 '집중 리스크'라는 심각한 위험을 만듭니다. 이는 제가 경험했던 소프트웨어 공급망 보안 문제와 정확히 같은 구조를 가집니다. 예를 들어, 특정 리눅스 배포판을 기반으로 한 '베이스 컨테이너 이미지'에 보안 취약점이 발견되면, 그 이미지를 사용한 수만 개의 애플리케이션이 동시에 위험에 노출됩니다. 마찬가지로, 만약 하나의 파운데이션 모델에 특정 편향이나 보안 취약점이 내재되어 있다면, 그 모델을 기반으로 만들어진 모든 AI 서비스가 그 문제점을 그대로 물려받아 사회 전체에 악영향을 증폭시킬 수 있습니다. 따라서 파운데이션 모델의 확산은 개발 단계에서의 철저한 검증과 지속적인 모니터링, 그리고 투명한 관리 체계가 얼마나 중요한지를 다시 한번 일깨워준다고 생각합니다.
