## 흐름 요약 (2021 → 2026)
- 2021: 초거대 모델 경쟁 + 멀티모달·코드로 확장, 파운데이션 모델 개념화.
- 2022: 이미지 생성 대중화 → ChatGPT로 대화형 AI 폭발.
- 2023: 멀티모달 표준화 + 검색 결합 + 오픈소스 LLM + 안전 규제 논의.
- 2024: 실시간 통합 멀티모달 + 영상 생성 + 소형 고성능 모델.
- 2025: 추론 모델 + 저비용 오픈 가중치(DeepSeek) + 초대형 인프라 투자.
- 2026: 출시 가속 + 장기 컨텍스트 + 에이전트·보안 지출 급증.

## 면접 활용 팁
- 연도별 §6(발표 주제 후보)에서 PT 주제를 고르고, §2(대표 뉴스) 출처로 근거를 보강한다.
- §7(예상 꼬리질문)에는 지원자 배경(컨테이너 보안, 시스템 콜 동적 관측 기반 이상탐지, Linux 커널 이해)을 연계한 답변이 포함돼 있다.
- 모든 §2 뉴스 항목과 §8 참고문헌은 실제 검색으로 확인한 URL만 사용했다.
