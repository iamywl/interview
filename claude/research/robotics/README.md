# 로봇 · 휴머노이드 (robotics) — 연도별 인덱스

SSAFY PT면접 대비 IT 시사 자료. 주제: **로봇·휴머노이드**. 연도 범위 2021~2026(2026은 1~6월).

## 연도별 자료
- [2021](./2021.md) — 옵티머스 콘셉트 발표, 현대차-보스턴 다이내믹스 인수, 유니트리 Go1 보급형 사족로봇
- [2022](./2022.md) — 옵티머스 실물 시제품('범블비'), Figure AI 설립, 아마존 프로테우스 자율 물류로봇
- [2023](./2023.md) — 옵티머스 Gen 2(촉각 손), 삼성-레인보우로보틱스 투자, 두산로보틱스 상장, Embodied AI
- [2024](./2024.md) — OpenAI×Figure 6.75억 달러, 엔비디아 GR00T·Jetson Thor, We Robot 원격조종 논란
- [2025](./2025.md) — Figure Helix·BotQ·390억 달러, 엔비디아 GR00T N1, 유니트리 G1 저가 양산, 옵티머스 목표 축소
- [2026](./2026.md) — 전기형 아틀라스 CES 공개·연 3만 대 계획, 옵티머스 손 재설계, 유니트리 G1 소매 판매

## 한눈에 보는 흐름
- **2021~2022**: 콘셉트→실물 시제품. 휴머노이드 전문 스타트업(Figure AI) 출현, 한국 대기업의 로봇 진입(현대차·삼성).
- **2023~2024**: 생성형 AI 결합(Embodied AI), 빅테크 자본·파운데이션 모델(GR00T), 실제 공장 실증(Figure-BMW).
- **2025~2026**: 양산 인프라·자본 폭증, 미·중 진영 분화, 손재주·액추에이터 병목, '상업적 임계점' 진입.

## 핵심 키워드 맵
- **휴머노이드 3강 구도**: 테슬라 옵티머스 / Figure AI / 보스턴 다이내믹스(현대차) + 중국 유니트리(저가)
- **플랫폼**: 엔비디아 Isaac GR00T·Jetson Thor·Newton(시뮬레이션)
- **한국**: 현대차-보스턴 다이내믹스(아틀라스), 삼성-레인보우로보틱스, 두산로보틱스(협동로봇)
- **병목 기술**: 손재주(dexterity)·액추에이터, Sim2Real, 안전 제어, 양산 원가

## 지원자 배경 연계 포인트(꼬리질문용)
컨테이너 보안·시스템콜 동적 관측 기반 이상탐지·Linux 커널 이해 → 로봇 동작 로그 기반 이상탐지, 엣지 디바이스 무결성·격리, 대규모 로봇 OTA 배포의 권한 최소화에 연계. ROS·임베디드·실시간 제어는 연계 가능하나 추가 학습 단계임을 과장 없이 밝힌다.
