## 2023 · 오픈소스 · 개발자 생태계

### 1. 그해 핵심 트렌드
2023년 오픈소스 생태계의 두 키워드는 **라이선스 리라이선싱**과 **오픈 LLM**이다. 8월 HashiCorp가 Terraform을 BSL로 전환하자 커뮤니티가 OpenTofu로 포크하며 "오픈소스 벤더의 비즈니스 모델 vs 커뮤니티" 갈등이 다시 폭발했다. 동시에 Meta Llama 2(7월)와 Mistral 7B(9월)가 공개되며 **누구나 받아 쓰는 오픈 가중치 LLM 경쟁**이 시작됐다. 단, Llama 2의 커스텀 라이선스를 둘러싸고 "이것이 진짜 오픈소스인가"라는 정의 논쟁도 함께 불거졌다.

### 2. 대표 뉴스·사건
- **HashiCorp Terraform BSL 전환**: 2023년 8월 10일 HashiCorp가 Terraform을 MPL 2.0에서 Business Source License(BSL)로 변경했다. 1.5.x 이전 버전은 오픈소스로 남지만 이후 버전은 BSL의 제약을 받게 됐다 ([Spacelift](https://spacelift.io/blog/terraform-license-change)).
- **OpenTofu 포크 선언**: 2023년 8월 25일 OpenTF 이니셔티브가 Terraform의 오픈소스 포크를 발표했다. 매니페스토는 한 달 만에 3만 3천 개 이상 스타와 약 140개 기업·700명 개인의 지지를 받았다 ([OpenTofu Blog](https://opentofu.org/blog/opentofu-announces-fork-of-terraform/)).
- **OpenTofu, Linux Foundation 합류**: 2023년 9월 20일 Linux Foundation이 OpenTF를 프로젝트로 받아들이며 OpenTofu로 개명됐다. MPL 2.0으로 복귀하고 Terraform과 CLI 호환을 유지했다 ([OpenTofu Blog](https://opentofu.org/blog/opentofu-announces-fork-of-terraform/)).
- **Meta Llama 2 공개**: 2023년 7월 18일 Meta가 Llama 2를 연구·상업 사용 무료로 공개했다. 다만 월 7억 명 이상 활성 사용자 기업은 별도 허가가 필요하고, Llama 2 출력으로 타 LLM 학습을 금지하는 등 제약이 있어 OSI는 이를 오픈소스로 승인하지 않았다 ([The Register, 2023-07-21](https://www.theregister.com/2023/07/21/llama_is_not_open_source/)).
- **Mistral 7B 공개**: 2023년 9월 27일 Mistral AI가 73억 파라미터 모델 Mistral 7B를 Apache 2.0 라이선스로 공개했다. 제약 없는 진정한 오픈 가중치 모델로, Llama 2 13B를 전 벤치마크에서 능가한다고 주장했다 ([Mistral AI](https://mistral.ai/news/announcing-mistral-7b/)).
- **Mixtral 8x7B(MoE) 공개**: 2023년 12월 Mistral AI가 전문가 혼합(MoE) 구조의 Mixtral을 공개하며 오픈 가중치 모델의 효율성 경쟁을 가속했다 ([Mistral AI](https://mistral.ai/news/mixtral-of-experts/)).

### 3. 핵심 기업·제품·기술 키워드
- **라이선스**: BSL(BUSL), MPL 2.0, OpenTofu, OpenTF Manifesto, 리라이선싱
- **오픈 LLM**: Meta Llama 2, Mistral 7B, Mixtral 8x7B(MoE), Apache 2.0 모델, Hugging Face
- **거버넌스**: Linux Foundation, OSI(오픈소스 정의 논쟁), Technical Steering Committee
- **IaC·DevOps**: Terraform, OpenTofu, Infrastructure as Code

### 4. 시장 수치·전망
- OpenTF 매니페스토 한 달 내 3만 3천+ 스타, 약 140개 기업·700명 개인 지지 ([OpenTofu Blog](https://opentofu.org/blog/opentofu-announces-fork-of-terraform/)).
- Mistral 7B 파라미터 73억 개, Apache 2.0 라이선스 ([Mistral AI](https://mistral.ai/news/announcing-mistral-7b/)).
- Llama 2 라이선스 제약 기준: 월 활성 사용자 7억 명 초과 시 별도 허가 필요 ([The Register, 2023-07-21](https://www.theregister.com/2023/07/21/llama_is_not_open_source/)).

### 5. 전년 대비 변화점
- **새로 뜬 것**: 핵심 인프라 도구(Terraform)의 BSL 전환과 즉각적 커뮤니티 포크(OpenTofu), 텍스트 LLM 영역의 오픈 가중치 경쟁(Llama 2/Mistral).
- **식은 것**: "오픈 가중치 = 오픈소스" 등식. Llama 2 라이선스 논쟁으로 OSI 정의 기준의 중요성이 부각됐다.

### 6. PT 발표 주제 후보
- **오픈소스 리라이선싱과 커뮤니티 포크**: HashiCorp BSL 전환과 OpenTofu가 보여준 오픈소스 거버넌스의 회복력.
- **오픈 LLM 경쟁의 개막**: Llama 2와 Mistral 7B가 만든 "받아서 돌리는 LLM" 시대.
- **무엇이 진짜 오픈소스인가**: Llama 2 라이선스 논쟁으로 본 오픈소스 정의의 재검토.

### 7. 예상 꼬리질문 + 답변 포인트
- **Q. Terraform 같은 인프라 도구의 라이선스 변경이 운영에 주는 영향은?**
  A. BSL은 경쟁 제품 제공을 제한하므로, 사내에서 관리형 IaC 서비스를 제공하거나 도구를 재배포할 때 법적 검토가 필요하다. OpenTofu는 CLI 호환을 유지해 마이그레이션 비용이 낮지만, 모듈·프로바이더 생태계 분화 리스크는 추적해야 한다. 컨테이너·인프라를 코드로 다루는 입장에서 의존 도구의 라이선스 변화는 곧 운영 리스크다.
- **Q. 오픈 가중치 LLM을 컨테이너 환경에서 안전하게 운영하려면?**
  A. 모델 가중치도 외부 의존성이므로 출처·해시·라이선스를 검증하고, 추론 컨테이너를 최소 권한으로 격리한다. 프롬프트 인젝션이나 비정상 외부 호출은 런타임에서 잡아야 한다. 제가 다룬 시스템 콜 동적 관측 기반 이상탐지를 추론 컨테이너에 적용하면, 모델이 유발하는 예기치 않은 파일·네트워크 접근을 행위 기반으로 탐지할 수 있다.
- **Q. OSI가 Llama 2를 오픈소스로 인정하지 않은 이유는?**
  A. OSI 정의는 사용 분야·대상에 차별을 두지 않을 것을 요구하는데, Llama 2는 월 7억 사용자 이상 기업 제한과 타 LLM 학습 금지 조항이 있어 이를 위반한다. 즉 "무료 사용 가능"과 "오픈소스"는 다른 개념이다. 풀스택 개발자로서 의존성을 채택할 때 라이선스 조항을 정확히 읽는 습관이 중요하다고 본다.
