## 2022 · 오픈소스 · 개발자 생태계

### 1. 그해 핵심 트렌드
2022년은 **오픈소스 공급망 보안이 제도화된 해**다. Log4Shell의 충격 이후 백악관이 주도해 OpenSSF Alpha-Omega 프로젝트가 출범했고, SLSA·SBOM이 미국 행정명령 14028과 연계되며 공식 표준 작업으로 자리 잡았다. 동시에 **AI 코딩 도구가 상용화**됐다. GitHub Copilot이 6월 정식 출시(월 10달러)되며 유료 제품이 됐다. 하반기에는 **오픈 가중치 모델**의 출발점이 된 Stable Diffusion이 8월 공개되어, 오픈소스 AI 모델 생태계의 토대가 마련됐다.

### 2. 대표 뉴스·사건
- **OpenSSF Alpha-Omega 프로젝트 출범**: 2022년 2월 백악관 회의 이후 OpenSSF가 Alpha-Omega 프로젝트를 발표했다. Microsoft·Google이 초기 500만 달러를 투자해 핵심 OSS 유지보수자 지원(Alpha)과 1만 개 이상 프로젝트의 취약점 자동 탐지(Omega)를 목표로 삼았다 ([Help Net Security, 2022-02-02](https://www.helpnetsecurity.com/2022/02/02/openssf-alpha-omega-project/)).
- **SLSA·SBOM 표준화 본격화**: OpenSSF 공급망 무결성 워킹그룹이 SLSA(Supply chain Levels for Software Artifacts)를 정교화했고, SBOM 도구가 미국 행정명령 14028의 투명성 요건과 정렬됐다 ([PR Newswire, 2022-02-01](https://www.prnewswire.com/news-releases/openssf-announces-the-alpha-omega-project-to-improve-software-supply-chain-security-for-10-000-oss-projects-301472316.html)).
- **GitHub Copilot 정식 출시**: 2022년 6월 21일 GitHub가 1년 기술 프리뷰를 거친 Copilot을 모든 개발자에게 월 10달러(연 100달러)에 정식 출시했다. 학생과 인기 오픈소스 유지보수자에게는 무료로 제공했다 ([GitHub Blog, 2022-06-21](https://github.blog/news-insights/product-news/github-copilot-is-generally-available-to-all-developers/)).
- **Stable Diffusion 공개**: 2022년 8월 22일 Stability AI가 CompVis·Runway와 함께 텍스트-이미지 모델 Stable Diffusion 1.4를 가중치까지 공개했다. 소비자용 GPU(VRAM 2.4GB 수준)에서도 구동 가능해 로컬 추론·파인튜닝 생태계가 폭발적으로 확장됐다 ([Wikipedia](https://en.wikipedia.org/wiki/Stable_Diffusion)).
- **Stable Diffusion 오픈 가중치 모델 정착**: Stable Diffusion은 가중치 다운로드와 상업적 사용을 허용하는 라이선스로, 로컬 추론 도구·파인튜닝 커뮤니티·상용 서비스 생태계의 기반이 됐다 ([Open Source For You, 2022-09](https://www.opensourceforu.com/2022/09/image-generation-model-stable-diffusion-is-now-open-source/)).
- **GitHub Copilot 저작권 논쟁 점화**: Copilot의 GA와 함께 공개 코드 학습에 따른 라이선스·저작권 문제가 제기됐고, 이후 집단소송으로 이어졌다 ([Wikipedia](https://en.wikipedia.org/wiki/GitHub_Copilot)).

### 3. 핵심 기업·제품·기술 키워드
- **공급망 보안**: OpenSSF, Alpha-Omega, SLSA, SBOM, 행정명령 14028, Scorecard
- **AI 코딩**: GitHub Copilot(GA), OpenAI Codex
- **오픈 AI 모델**: Stable Diffusion, Stability AI, Hugging Face, LAION-5B
- **거버넌스·투자**: Microsoft, Google, Linux Foundation, 백악관 OSS 보안 회의

### 4. 시장 수치·전망
- Alpha-Omega 초기 투자 500만 달러, Omega 목표 대상 1만 개 이상 OSS 프로젝트(목표치) ([Help Net Security, 2022-02-02](https://www.helpnetsecurity.com/2022/02/02/openssf-alpha-omega-project/)).
- GitHub Copilot 정식 요금 월 10달러/연 100달러 ([Visual Studio Magazine, 2022-06-21](https://visualstudiomagazine.com/articles/2022/06/21/github-copilot-ga.aspx)).
- Stable Diffusion 최소 구동 요건 VRAM 약 2.4GB로 보급형 하드웨어 추론이 가능해짐 ([Wikipedia](https://en.wikipedia.org/wiki/Stable_Diffusion)).

### 5. 전년 대비 변화점
- **새로 뜬 것**: 정부·산업 협력형 공급망 보안 거버넌스(OpenSSF Alpha-Omega), 유료 상용 AI 코딩 제품, 오픈 가중치 생성 AI 모델.
- **식은 것**: Log4Shell 직후의 "긴급 패치" 단계에서, 표준·자동화 기반의 상시 관리 체계로 무게중심이 이동했다.

### 6. PT 발표 주제 후보
- **오픈소스 공급망 보안의 제도화**: Log4Shell 이후 OpenSSF·SLSA·SBOM이 어떻게 보안을 표준 작업으로 바꿨는가.
- **AI 코딩 도구의 상용화와 라이선스 딜레마**: Copilot GA가 연 생산성 향상과 공개 코드 학습 저작권 논쟁.
- **오픈 가중치 모델 생태계의 탄생**: Stable Diffusion이 보여준 "모델을 오픈소스로 푸는 것"의 파급력.

### 7. 예상 꼬리질문 + 답변 포인트
- **Q. SBOM과 SLSA의 차이를 설명해보라.**
  A. SBOM은 소프트웨어에 어떤 구성요소·의존성이 들어 있는지를 명세하는 "재료 목록"이고, SLSA는 빌드·배포 과정의 무결성을 단계별로 검증하는 "절차 표준"이다. SBOM은 무엇이 들어있는지, SLSA는 변조 없이 만들어졌는지를 보장한다. 컨테이너 보안 관점에서 보면 이미지 빌드 파이프라인에 두 가지를 함께 적용해야 의존성 가시성과 빌드 신뢰성을 모두 확보할 수 있다.
- **Q. AI 코딩 도구가 생성한 코드의 보안을 어떻게 검증하나?**
  A. 생성 코드는 학습 데이터의 취약 패턴을 그대로 답습할 수 있으므로 정적 분석·의존성 스캔으로 1차 검증한다. 다만 실제 동작 시점의 위험은 런타임 관측이 필요하다. 제가 다룬 시스템 콜 동적 관측 기반 이상탐지를 적용하면, 코드가 어떤 출처에서 생성됐든 실행 시 비정상 행위를 행위 기반으로 잡아낼 수 있다.
- **Q. 오픈 가중치 모델의 보안·라이선스 리스크는?**
  A. 가중치를 받아 로컬에서 파인튜닝·배포할 수 있는 만큼, 모델 출처·라이선스 추적과 악성 가중치(백도어된 모델) 검증이 필요하다. 또한 Stable Diffusion처럼 데이터셋 라이선스가 결과물 저작권에 영향을 줄 수 있어, 풀스택 개발 관점에서 모델도 일반 의존성처럼 공급망 관리 대상으로 봐야 한다.
