## 큰 흐름 한눈에
1. **전기차**: EV 전용 플랫폼 경쟁(2021) → IRA 공급망 정책(2022) → 캐즘·가격 전쟁(2023~2024) → 보조금 폐지·현지화(2025) → BYD vs 테슬라 패권(2026).
2. **자율주행**: 로보택시 허가(2021) → 규제 강화(2022) → 크루즈 사태·FSD v12(2023) → 크루즈 철수·웨이모 확장(2024) → 테슬라 로보택시 시동(2025) → 사이버캡 양산·고속도로 운행(2026).
3. **공통 쟁점**: 카메라 vs 라이다, 안전 검증·관측 가능성, 충전 인프라, 배터리 원가(LFP)·안전(화재).
