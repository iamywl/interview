# 한국 IT · 삼성 (slug: `korea_it`)

SSAFY PT면접 대비 IT 시사 자료 — 주제: **한국 IT · 삼성 (지원동기 연계)**.
삼성전자 전략·반도체·갤럭시·삼성 가우스/AI, 네이버·카카오·쿠팡, 한국 정부 디지털 정책(디지털플랫폼정부·K-클라우드·AI 기본법), 한국 AI 반도체(NPU), SSAFY를 연도별로 정리한다.
모든 항목은 실제 뉴스·공식 발표를 근거로 하며, 지원자 배경(컨테이너 보안·시스템콜 동적 관측 기반 이상탐지·Linux 커널·풀스택/코딩테스트 확장)과 삼성/SSAFY 지원동기를 §7 꼬리질문에 연계했다.

## 연도별 인덱스
- [2021](./2021.md) — 시스템반도체 171조원, 쿠팡·카뱅·카페이 IPO, 디지털 뉴딜 2.0(데이터댐), 하이퍼클로바
- [2022](./2022.md) — 세계 최초 3나노 GAA, 카카오 먹통(판교 화재), 디지털플랫폼정부 출범, 갤럭시 S22 GOS, 메모리 한파
- [2023](./2023.md) — 반도체 14년 만 적자·감산, 하이퍼클로바X, K-클라우드·국산 NPU, 갤럭시 S23, HBM 부상
- [2024](./2024.md) — 갤럭시 S24·갤럭시 AI(온디바이스), 삼성 가우스, HBM 패권 경쟁, 삼성 반성문·파운드리 적자
- [2025](./2025.md) — 갤럭시 S25 AI 에이전트, SKT 유심 유출(BPFdoor), HBM3E 엔비디아 퀄 통과, 국가 AI 컴퓨팅 센터
- [2026](./2026.md) (1~6월) — AI 기본법 시행, HBM4 세계 최초 양산, 갤럭시 S26, 1분기 호실적·노조 총파업, 국산 NPU 공공 상용화

## 핵심 흐름 요약
- 삼성 반도체: 메모리 호황(2021) → 한파·적자·감산(2022~2023) → 위기 인정·HBM 추격(2024) → 엔비디아 퀄 통과·반등(2025) → HBM4 세계 최초 양산·역대급 흑자(2026).
- 삼성 모바일 AI: 갤럭시 AI 등장(2024) → AI 에이전트(2025) → 3세대 AI폰(2026).
- 정부 정책: 디지털 뉴딜·데이터댐(2021) → 디지털플랫폼정부(2022) → K-클라우드·국산 NPU(2023) → AI 3대 강국·국가 AI 컴퓨팅 센터(2025) → AI 기본법 시행(2026).
- 플랫폼·보안: 빅테크 IPO(2021) → 카카오 먹통(2022) → SKT 유심 유출(2025)로 인프라 보안·가용성 쟁점화.

## 면접 활용 가이드
- 지원동기 연결: 삼성전자의 반도체·온디바이스 AI·보안 과제는 컨테이너 보안과 시스템콜/eBPF 기반 런타임 이상탐지 연구와 직접 맞닿는다. SSAFY를 통해 저수준 시스템 이해를 풀스택·실서비스 역량으로 확장하려는 동기를 일관되게 연결한다.
- 보안 연계 사건: 카카오 먹통(가용성·이중화), SKT 유심 유출(BPFdoor·리눅스 커널 백도어), 공공 클라우드 멀티테넌시(격리·런타임 탐지)는 §7에서 지원자 경험과 강하게 묶을 수 있는 사례다.
- 출처 규칙: §2 각 항목과 §8에 실제 검색 URL을 명시. 수치·전망은 "전망/추정"으로 표기.
