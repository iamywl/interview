# 한국 IT · 삼성 (지원동기 연계) — 주제 인덱스

SSAFY PT면접 대비용 "한국 IT · 삼성" 주제 자료 모음이다. 삼성전자와 한국 IT 산업의 2021~2026년 흐름을 PT 발표·지원동기·기술 면접에 쓸 수 있게 정리했다. 지원자 배경(컨테이너 보안·시스템 콜 동적 관측·Linux 커널)을 연계한 모범답안을 포함한다.

## 메인 학습문서
- [STUDY.md](STUDY.md) — 6년치를 종합한 메인 공부자료. 핵심 개념 사전, 연도별 흐름, PT 발표 주제 추천, 모범답안집, 지원자 경험 연계 포인트, 빠른 암기 카드.

## 연도별 자료
- [2021.md](2021.md) — 플랫폼 대형 IPO 러시(쿠팡·카카오뱅크·카카오페이)와 삼성 시스템반도체 171조원 투자, 개발자 연봉 경쟁·SW 인력난.

- [2023.md](2023.md) — 생성형 AI 국산화(하이퍼클로바X·엑사원 2.0·가우스)와 DS부문 약 15조 적자·25년 만의 감산, HBM이라는 출구.
- [2024.md](2024.md) — 갤럭시 S24 온디바이스 AI 대중화, HBM 퀄 지연·'송구' 메시지·DS 수장 교체, AI 기본법 통과.
- [2025.md](2025.md) — HBM3E 12단 엔비디아 퀄 통과로 메모리 반등, SKT 유심 유출(BPFdoor) 2,696만 건, 소버린 AI 구체화·GPU 26만 장.
