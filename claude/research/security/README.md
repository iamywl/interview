# 보안 · 제로트러스트 · 랜섬웨어 (`security`)

SSAFY PT면접 대비 IT 시사 자료. 연도별로 "그해 핵심 트렌드 → 대표 뉴스·사건 → 키워드 → 시장 수치 → 전년 대비 변화 → PT 주제 후보 → 예상 꼬리질문 → 참고문헌" 순으로 정리했다.

## 연도별 자료
- [2021](./2021.md) — 콜로니얼 파이프라인, 카세야, Log4Shell, 행정명령 14028(제로트러스트), RaaS 산업화
- [2022](./2022.md) — OMB M-22-09(제로트러스트 의무화), Lapsus$/Okta, 코스타리카 Conti, MFA 피로 공격, 와이퍼
- [2023](./2023.md) — MOVEit/Cl0p 대량 갈취, CISA ZTMM 2.0, OWASP LLM Top 10, 랜섬 지급 10억 달러 돌파, LG유플러스
- [2024](./2024.md) — Change Healthcare, Operation Cronos(LockBit 단속), CrowdStrike 대장애, NIST 양자내성암호 표준
- [2025](./2025.md) — SK텔레콤 BPFdoor 사태, Salt Typhoon 통신사 침투, 트럼프 사이버 EO, AI 기반 랜섬웨어 급증
- [2026 (1~6월)](./2026.md) — 에이전틱 AI 신원 보안, 머신 신원 폭증, BYOVD/EDR 킬러, 취약점 악용 1순위, 공급망 침해 4배

## 6년 흐름 요약
- **랜섬웨어**: 암호화(2021) → 이중 갈취(2022) → 대량 공급망 갈취(2023) → 단속·지급 감소(2024) → AI 자동화(2025) → 갈취 전용·EDR 킬러(2026).
- **제로트러스트**: 행정명령 권고(2021) → 의무화(2022) → 성숙도 모델(2023) → 정책 유지·재편(2025) → AI 에이전트 신원으로 재정의(2026).
- **공급망**: SolarWinds·Log4Shell(2021) → MOVEit(2023) → CrowdStrike(2024, 방어자발 장애) → SaaS·빌드환경(2026).
- **국가 배후**: 우크라이나 와이퍼(2022) → Salt Typhoon·BPFdoor 통신 인프라(2025).

## 지원자 강점 연계 포인트
이 주제는 지원자 핵심 강점이다. 꼬리질문 답변에 다음을 깊이 연결했다.
- **컨테이너 보안 연구**: 워크로드 단위 최소 권한, 마이크로세그멘테이션, 에이전트 격리.
- **시스템 콜 동적 관측 기반 이상탐지**: 웹셸(MOVEit), 갈취 반출, 장기 잠복 백도어(BPFdoor) 런타임 탐지.
- **Linux 커널 이해**: BPFdoor·BYOVD·CrowdStrike 등 커널 수준 사건의 원리와 eBPF 기반 방어.
- **풀스택·확장성**: 양자내성암호 마이그레이션, 자율 SOC 트리아지 등 실무 구현.
