## 보안 · 제로트러스트 · 랜섬웨어 — 주제 인덱스

SSAFY PT면접 대비 IT 시사 학습자료 중 "보안 · 제로트러스트 · 랜섬웨어"(slug=security) 주제의 연도별 자료 인덱스다. 2021~2026년 6년치 흐름과 이를 종합한 메인 학습문서를 담는다.

### 메인 학습문서
- [STUDY.md](STUDY.md) — 6년치를 종합한 메인 공부자료. 핵심 개념 사전, 연도별 흐름, PT 발표 주제 추천, 모범답안집(11개), 지원자 경험 연계 포인트, 빠른 암기 카드를 담았다. 면접 직전 이 파일부터 본다.

### 연도별 자료
- [2021.md](2021.md) — 콜로니얼 파이프라인·Log4Shell·카세야로 랜섬웨어가 국가 안보 의제로 격상되고, 행정명령 14028로 제로트러스트가 정책 표준으로 등장한 해.
- [2022.md](2022.md) — OMB M-22-09로 제로트러스트가 연방 의무가 되고, Lapsus$의 MFA 피로 공격·러우전쟁 와이퍼·코스타리카 국가 비상사태가 신원·국가전 위협을 부각한 해.
- [2023.md](2023.md) — MOVEit 제로데이 대량 갈취가 정점에 달하고 랜섬 지급액이 사상 첫 11억 달러를 돌파했으며, OWASP LLM Top 10·CISA ZTMM 2.0이 등장한 해.
- [2024.md](2024.md) — Change Healthcare 의료 인프라 공격, Operation Cronos의 LockBit 단속, CrowdStrike 대장애, NIST 양자내성암호 표준 3종 발표가 갈린 해.
- [2025.md](2025.md) — 한국 통신 3사가 모두 BPFDoor에 뚫리고, Salt Typhoon이 미 합법감청 시스템까지 침투했으며, AI가 공격의 80~90%를 자율 수행한 첫 사례가 보고된 해.
- [2026.md](2026.md) — 취약점 악용이 침투 1순위로 등극하고, 머신 신원 폭증이 제로트러스트 첫 기둥을 재정의했으며, 갈취형 랜섬웨어·BYOVD 기반 EDR 킬러가 표준이 된 해(상반기 기준).
