## 2021 · 데이터 · 빅데이터 · 벡터DB

### 1. 그해 핵심 트렌드
2021년은 클라우드 데이터 플랫폼 기업이 자본시장에서 본격적으로 검증받은 해다. 2020년 9월 상장한 Snowflake가 연 매출 10억 달러를 넘기며 "데이터 클라우드"를 확산시켰고, 경쟁사 Databricks는 "레이크하우스(lakehouse)" 개념을 전면에 내세워 데이터 웨어하우스와 데이터 레이크를 하나의 아키텍처로 통합하려 했다. 실시간 스트리밍 처리의 핵심인 Apache Kafka 상용화 기업 Confluent가 상장하며 "데이터 인 모션(data in motion)" 시장이 부각됐다. 조직 구조 측면에서는 도메인 중심으로 데이터 소유권을 분산하는 데이터 메시(data mesh)와, Gartner가 그해 주요 트렌드로 꼽은 데이터 패브릭(data fabric) 논의가 데이터 엔지니어링 담론을 주도했다. 이 시점에는 벡터DB가 아직 주류 키워드가 아니었다.

### 2. 대표 뉴스·사건
- Databricks가 2021년 2월 시리즈 G 10억 달러 투자를 280억 달러 밸류에이션으로 유치하며 IPO와 Snowflake 추격을 동시에 겨냥했다 ([SiliconANGLE, 2021-02-01](https://siliconangle.com/2021/02/01/massive-1b-infusion-databricks-takes-aim-ipo-rival-snowflake/)).
- Databricks가 그해 후반 시리즈 H에서 16억 달러를 380억 달러 밸류에이션으로 추가 조달하며, Apache Spark 기반 통합 데이터 플랫폼 전략을 강화했다 ([SiliconANGLE, 2021-02-01](https://siliconangle.com/2021/02/01/massive-1b-infusion-databricks-takes-aim-ipo-rival-snowflake/)).
- Confluent가 2021년 6월 24일 나스닥에 상장(티커 CFLT), 주당 36달러로 2,300만 주를 공모해 약 8억 2,800만 달러를 조달했고 거래 첫날 25% 급등하며 시가총액 약 114억 달러를 기록했다 ([CNBC, 2021-06-24](https://www.cnbc.com/2021/06/24/confluent-climbs-26percent-after-raising-828-million-in-ipo.html)).
- Confluent는 S-1에서 고객 2,500개 이상, 2021년 1분기 매출 전년 대비 51% 성장을 공개하고 잠재 시장(TAM)을 최대 500억 달러로 추정했다 ([TechTarget, 2021-06](https://www.techtarget.com/searchdatamanagement/news/252502989/Confluent-goes-IPO-as-Kafka-event-streaming-goes-mainstream)).
- Databricks가 데이터 레이크와 데이터 웨어하우스를 단일 플랫폼으로 통합하는 "레이크하우스" 아키텍처를 전면에 내세우며, Delta Lake(2019년 Linux Foundation에 오픈소스화) 위에 ACID 트랜잭션과 거버넌스를 결합했다 ([Databricks Blog, 2020-09-10](https://www.databricks.com/blog/2020/09/10/diving-deep-into-the-inner-workings-of-the-lakehouse-and-delta-lake.html)).
- Snowflake가 2018년 9,600만 달러였던 매출을 2021년 10억 달러 이상으로 끌어올리며, 클라우드 데이터 웨어하우스에서 "데이터 클라우드"로 포지셔닝을 확장했다 ([Tietoevry, 2021-09](https://www.tietoevry.com/en/blog/2021/09/data-lakes-and-warehouses-databricks-snowflake/)).

### 3. 핵심 기업·제품·기술 키워드
- 기업/제품: Snowflake(데이터 클라우드), Databricks(레이크하우스·Delta Lake), Confluent(Kafka·data in motion)
- 테이블 포맷: Delta Lake, Apache Iceberg(2017년 Netflix 발), Apache Hudi
- 아키텍처/개념: 레이크하우스, 데이터 메시, 데이터 패브릭, 스트리밍/이벤트 처리(Apache Kafka·Flink)
- 처리 엔진: Apache Spark, Apache Flink, Trino/Presto

### 4. 시장 수치·전망
- Snowflake: 2021년 연 매출 10억 달러 돌파, 2022년 20억 달러 돌파 전망(전년 대비 60%+ 성장 추정) ([Tietoevry, 2021-09](https://www.tietoevry.com/en/blog/2021/09/data-lakes-and-warehouses-databricks-snowflake/)).
- Databricks: 2021년 시리즈 H 기준 밸류에이션 380억 달러 ([SiliconANGLE, 2021-02-01](https://siliconangle.com/2021/02/01/massive-1b-infusion-databricks-takes-aim-ipo-rival-snowflake/)).
- Confluent: 잠재 시장(TAM) 최대 500억 달러 추정, 상장 시 시가총액 약 114억 달러 ([TechTarget, 2021-06](https://www.techtarget.com/searchdatamanagement/news/252502989/Confluent-goes-IPO-as-Kafka-event-streaming-goes-mainstream)).

### 5. 전년 대비 변화점
- 새로 뜬 것: 레이크하우스가 마케팅 용어를 넘어 실제 채택 사례로 확산. Confluent 상장으로 스트리밍이 독립 시장 카테고리로 인정받음. 데이터 메시/패브릭 같은 조직·아키텍처 담론 부상.
- 식은 것: 단순 온프레미스 Hadoop 중심 빅데이터 담론이 클라우드 네이티브 플랫폼으로 대체됨.
- 아직 없던 것: 벡터DB·RAG는 주류 키워드가 아니었다. 이들은 2022~2023년 생성형 AI 확산 이후 부상한다.

### 6. PT 발표 주제 후보
- "레이크하우스는 무엇을 통합했나" — 데이터 레이크와 웨어하우스의 한계를 단일 아키텍처로 묶은 배경과 의미.
- "데이터 인 모션: Kafka가 만든 실시간 데이터 시장" — Confluent 상장으로 본 스트리밍 처리의 부상.
- "데이터 메시: 중앙집중 데이터팀의 한계와 도메인 분산" — 조직 관점 데이터 거버넌스 변화.

### 7. 예상 꼬리질문 + 답변 포인트
- Q: 데이터 레이크와 데이터 웨어하우스의 차이는?
  A: 웨어하우스는 스키마가 고정된 정형 데이터를 정해진 구조로 저장해 분석에 최적화하고, 레이크는 비정형·반정형 데이터를 원본 형태로 저장해 유연하다. 레이크하우스는 레이크의 저비용 스토리지 위에 Delta Lake 같은 테이블 포맷으로 ACID 트랜잭션과 스키마를 부여해 둘을 합친 구조다.
- Q: 스트리밍 처리가 왜 중요한가?
  A: 배치는 일정 주기로 모아 처리해 지연이 크고, 스트리밍은 이벤트 발생 즉시 처리해 실시간 대응이 가능하다. 제 경험인 시스템 콜 동적 관측 기반 이상탐지도 본질적으로 이벤트 스트림을 실시간 처리하는 문제였고, Kafka 같은 메시지 큐는 그 이벤트를 수집·전달하는 표준 인프라로 이해하고 있다. 풀스택으로 확장하면서 데이터 파이프라인 설계와 연결해 학습할 부분이다.
- Q: 데이터 메시가 기존 중앙 데이터팀과 다른 점은?
  A: 중앙 데이터팀이 모든 파이프라인을 떠맡으면 병목이 생긴다. 데이터 메시는 도메인 팀이 자기 데이터를 "제품"처럼 소유·제공하게 해 셀프서비스로 분산한다. 다만 분산은 거버넌스·품질 관리 비용을 키워, 이를 표준화하는 셀프서비스 플랫폼이 전제되어야 한다는 점도 이해하고 있다.
