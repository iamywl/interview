## 2022 · 데이터 · 빅데이터 · 벡터DB

### 1. 그해 핵심 트렌드
2022년은 데이터 플랫폼 시장이 성숙하면서 동시에 거버넌스가 핵심 과제로 떠오른 해다. Snowflake와 Databricks는 각각 데이터 웨어하우스와 데이터 사이언스 진영에서 출발해 서로의 영역으로 확장하며 정면 충돌했고, 매출은 둘 다 10억 달러를 넘어섰다. 데이터 품질·계보(lineage)·접근 통제·규제 준수를 다루는 데이터 거버넌스가 정형 데이터를 넘어 비정형·반정형 데이터까지 포괄해야 한다는 요구가 커졌다. 한편 벡터DB 기업들이 조용히 시리즈 투자를 받으며 기반을 다졌으나(Weaviate 시리즈 B 5,000만 달러), 시장의 폭발은 그해 11월 ChatGPT 출시 직후부터 시작된다. 2022년은 벡터DB·RAG가 주류로 넘어가기 직전의 분기점이다.

### 2. 대표 뉴스·사건
- Weaviate가 2022년 4월 시리즈 B 5,000만 달러를 유치하고 오픈소스 다운로드 200만 건을 돌파하며 벡터 검색 인프라 기반을 다졌다 ([Pinecone, 2023](https://www.pinecone.io/lp/weaviate/)).
- Snowflake가 2018년 9,600만 달러에서 2021년 10억 달러를 넘긴 매출을 2022년 20억 달러 돌파로 끌어올리며(전년 대비 60%+ 성장 전망) 데이터 플랫폼 시장 성장을 입증했다 ([SaaStr, 2022](https://www.saastr.com/databricks-vs-snowflake-at-5b-arr-same-revenue-2x-valuation-gap-heres-why/)).
- Databricks가 데이터 사이언스 진영에서 출발해 데이터 웨어하우스 영역으로, Snowflake가 데이터 웨어하우스에서 데이터 레이크/사이언스 영역으로 서로 확장하며 200억 달러+ 규모 데이터 시장에서 정면 경쟁 구도를 형성했다 ([Wing VC, 2022](https://www.wing.vc/content/comparing-the-financials-of-databricks-and-snowflake)).
- OECD가 2022년 "성장과 복지를 위한 데이터 거버넌스" 종합 보고서와 정책 형성 가이드를 발간하며, 데이터 거버넌스가 국제 정책 의제로 격상됐다 ([주OECD 대한민국 대표부, 2022](https://overseas.mofa.go.kr/oecd-ko/brd/m_20806/view.do?seq=402&page=1&srchFr=&srchTo=&srchTp=0&srchWord=)).
- 2022년 11월 ChatGPT 출시 직후, 사용자들이 LLM이 자기 데이터로 학습되지 않았음을 인식하면서 질의 시점에 외부 데이터를 검색해 프롬프트에 주입하는 RAG(검색증강생성) 접근과 LangChain 프레임워크가 등장했다 ([Towards Data Science, 2022](https://towardsdatascience.com/hitchhikers-guide-to-rag-with-chatgpt-api-and-langchain/)).
- 기업 데이터 거버넌스가 정형 데이터 중심에서 Hadoop·Spark 등 빅데이터 환경의 정형·비정형·반정형 데이터를 모두 포괄하는 방향으로 확장됐다 ([Databricks, 2022](https://www.databricks.com/discover/data-governance)).

### 3. 핵심 기업·제품·기술 키워드
- 기업/제품: Snowflake, Databricks(Unity Catalog 거버넌스), Confluent, Weaviate(벡터DB 초기)
- 거버넌스: 데이터 품질, 데이터 계보(lineage), 접근 통제, 규제 준수, Unity Catalog
- 신흥 키워드(연말): RAG, 임베딩(embedding), LangChain, 벡터 검색
- 테이블 포맷: Delta Lake, Apache Iceberg, Apache Hudi

### 4. 시장 수치·전망
- Snowflake: 2022년 매출 20억 달러 돌파 전망(전년 대비 60%+ 성장 추정) ([SaaStr, 2022](https://www.saastr.com/databricks-vs-snowflake-at-5b-arr-same-revenue-2x-valuation-gap-heres-why/)).
- Databricks: 2022년 무렵 ARR 10억 달러 돌파(투자 라운드 공개 기준 추정) ([SaaStr, 2022](https://www.saastr.com/databricks-vs-snowflake-at-5b-arr-same-revenue-2x-valuation-gap-heres-why/)).
- 전체 데이터 시장 규모: 200억 달러+ 추정 ([SaaStr, 2022](https://www.saastr.com/databricks-vs-snowflake-at-5b-arr-same-revenue-2x-valuation-gap-heres-why/)).
- Weaviate: 시리즈 B 5,000만 달러, 누적 투자 6,700만 달러 ([Pinecone, 2023](https://www.pinecone.io/lp/weaviate/)).

### 5. 전년 대비 변화점
- 새로 뜬 것: 데이터 거버넌스가 국제 정책(OECD)과 기업 플랫폼(Unity Catalog) 양쪽에서 핵심 의제로 격상. 연말 ChatGPT 출시로 RAG·LangChain·임베딩이 개발자 담론에 진입.
- 강화된 것: Snowflake-Databricks 양강 구도가 매출·기능 양면에서 정면 충돌로 굳어짐.
- 식기 시작한 것: 벡터DB는 아직 틈새였으나, 연말부터 급속히 주류로 이동하기 시작.

### 6. PT 발표 주제 후보

### 7. 예상 꼬리질문 + 답변 포인트
- Q: 데이터 거버넌스에서 데이터 계보(lineage)가 왜 중요한가?
  A: 계보는 데이터가 어디서 와서 어떤 변환을 거쳤는지 추적하는 것이다. 규제 준수와 오류 추적에 필수다. 제가 다룬 시스템 콜 관측 기반 이상탐지에서도 이벤트가 어느 프로세스·커널 경로에서 발생했는지 출처를 추적하는 것이 핵심이었는데, 데이터 계보도 같은 맥락의 추적 문제로 이해한다.
- Q: RAG가 왜 등장했나?
  A: LLM은 학습 시점 이후 데이터나 기업 내부 데이터를 모른다. RAG는 질의 시점에 관련 문서를 검색해 프롬프트에 붙여 환각을 줄이고 최신·내부 정보를 반영한다. 이 검색을 빠르고 확장 가능하게 하려면 임베딩을 저장·검색하는 벡터DB가 필요해졌다.
- Q: 비정형 데이터 거버넌스가 정형 데이터보다 어려운 이유는?
  A: 정형 데이터는 스키마와 제약이 명확해 품질·접근 통제 규칙을 정의하기 쉽다. 비정형 데이터는 구조가 없어 분류·품질 기준·민감정보 식별이 어렵다. 저는 풀스택으로 확장하면서 이 부분을 메타데이터 카탈로그와 자동 분류로 다루는 방식을 더 학습할 계획이다.
