## 데이터 · 빅데이터 · 벡터DB — 주제 인덱스

SSAFY PT면접 대비 "데이터 · 빅데이터 · 벡터DB"(slug=data) 주제의 연도별 자료와 종합 학습문서 인덱스다. 데이터 인프라가 "저장·분석"에서 "AI·에이전트가 직접 소비하는 인프라"로 진화한 2021~2026년의 흐름을 다룬다.

### 메인 학습문서
- [STUDY.md](STUDY.md) — 6년치를 종합한 메인 공부자료. 핵심 개념 사전, 연도별 흐름, PT 발표 주제 추천, 모범답안집, 지원자 경험 연계, 빠른 암기 카드를 담았다. **면접 직전 이 문서부터 본다.**

### 연도별 자료
- [2021.md](2021.md) — 클라우드 데이터 플랫폼 검증, 레이크하우스 부상, Confluent 상장과 "데이터 인 모션".
- [2022.md](2022.md) — 데이터 거버넌스의 정책 의제화, 연말 ChatGPT로 RAG·벡터DB가 태동한 전환점.
- [2023.md](2023.md) — 생성형 AI 폭발로 벡터DB·RAG 주류화, Databricks의 MosaicML 인수.
- [2024.md](2024.md) — Apache Iceberg "아이스버그 전쟁"(Tabular 인수·Polaris), Databricks 시리즈 J 620억 달러.
- [2025.md](2025.md) — 레이크하우스의 OLTP 흡수(Neon·Crunchy Data), "에이전트 준비된 데이터" 시대.
- [2026.md](2026.md) — "RAG 이후" 패러다임, MCP 표준화, Iceberg v3·Polaris 프로덕션화, Databricks IPO 행보.

### 큰 흐름 한눈에
- 2021~2022: 클라우드 데이터 플랫폼(웨어하우스·레이크하우스)과 스트리밍의 성숙, 거버넌스 부상.
- 2023: 생성형 AI가 벡터DB·RAG를 핵심 인프라로 끌어올림. 데이터와 AI 스택의 수렴 시작.
- 2024: 오픈 테이블 포맷(Iceberg)과 카탈로그 표준 경쟁, 자본 집중 가속.
- 2025~2026: 분석·운영·에이전트가 한 플랫폼으로 통합. 벡터는 데이터 타입으로 흡수, MCP가 표준 통로로.
