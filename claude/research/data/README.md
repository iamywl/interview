# 데이터 · 빅데이터 · 벡터DB (slug: `data`)

SSAFY PT면접 대비 IT 시사 자료 — 주제 "데이터 · 빅데이터 · 벡터DB"의 연도별 인덱스다.
각 파일은 그해의 핵심 트렌드, 대표 뉴스(출처 링크 포함), 기업·기술 키워드, 시장 수치·전망,
전년 대비 변화점, PT 발표 주제 후보, 예상 꼬리질문+답변(지원자 배경 연계), 참고문헌으로 구성된다.

## 연도별 자료
- [2021](./2021.md) — 레이크하우스 부상, Confluent(Kafka) 상장, 데이터 메시/패브릭 (벡터DB 이전)
- [2022](./2022.md) — 데이터 거버넌스 격상, Snowflake-Databricks 정면 충돌, 연말 ChatGPT로 RAG 태동
- [2023](./2023.md) — 벡터DB 급부상(Pinecone $100M), RAG 표준화, pgvector, Databricks의 MosaicML 인수
- [2024](./2024.md) — 아이스버그 전쟁(Tabular 인수·Polaris), 오픈 카탈로그, Databricks 시리즈 J $10B
- [2025](./2025.md) — 레이크하우스의 OLTP 흡수(Neon·Crunchy Data), 에이전트 준비된 데이터, Lakebase·Cortex
- [2026](./2026.md) — RAG 이후(컨텍스트 아키텍처·에이전트 메모리), MCP 표준화, Iceberg v3, Databricks IPO 전망

## 큰 흐름 한눈에
- 2021~2022: 클라우드 데이터 플랫폼(웨어하우스·레이크하우스)과 스트리밍의 성숙, 거버넌스 부상.
- 2023: 생성형 AI가 벡터DB·RAG를 핵심 인프라로 끌어올림. 데이터와 AI 스택의 수렴 시작.
- 2024: 오픈 테이블 포맷(Iceberg)과 카탈로그 표준 경쟁. 자본 집중 가속.
- 2025~2026: 분석·운영·에이전트가 한 플랫폼으로 통합. 벡터는 데이터 타입으로 흡수, MCP가 표준 통로로.
