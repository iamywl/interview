# 신기술 · 양자컴퓨팅 · 차세대 컴퓨팅 (emergingtech)

SSAFY PT면접 대비 IT 시사 학습자료. 주제: **신기술 · 양자컴퓨팅 · 차세대 컴퓨팅**.
연도별로 그해 핵심 트렌드, 대표 뉴스·사건(출처 링크), 기업·제품 키워드, 시장 수치·전망,
전년 대비 변화점, PT 발표 주제 후보, 예상 꼬리질문(지원자 배경 연계), 참고문헌을 정리했다.

## 핵심 흐름 (6년 요약)
- **하드웨어**: 큐비트 '수'(이글 127 → 오스프리 433 → 콘도르 1,121) 경쟁에서, 2023년 이후 '오류정정·논리 큐비트·내결함성'으로 축이 이동. 2024년 Google Willow의 'below threshold', 2025년 캣 큐비트(Ocelot)·위상학적 큐비트(Majorana 1) 등 아키텍처 경쟁으로 다변화.
- **보안(PQC)**: 2016년 시작한 NIST 표준화가 2022년 1차 선정 → 2024년 FIPS 203/204/205 확정 → 2025~2026년 실제 마이그레이션·시범전환·운영망 적용으로 진행. 한국은 KpqC 자국 표준과 2035 전환 로드맵 병행.
- **XR/공간컴퓨팅**: 2021년 메타 리브랜딩(메타버스) → 2023년 애플 비전프로(공간컴퓨팅 선언) → 2024년 출시·수요 부진으로 현실 인식 전환.
- **한국**: 2023년 국가 양자전략·육성법 → 2024년 연세대 IBM 시스템 원 도입 → 2025년 국산 20큐비트 클라우드 → 2026년 IonQ Tempo·양자클러스터로 산업화 전환.

## 지원자 배경 연계 포인트
- 컨테이너 보안·시스템콜 동적 관측 기반 이상탐지·Linux 커널 이해 → **PQC 전환의 런타임 영향 모니터링**, 양자-HPC 하이브리드의 격리·권한 추적과 연결.
- 풀스택·코딩테스트 확장 → **공간컴퓨팅(visionOS) 앱 개발**, 양자 SDK 응용 영역 학습 가능성.
- 핵심 메시지: 하드웨어 추격보다 **응용·소프트웨어·보안(PQC)**에서 한국·지원자의 강점을 찾는다.
