## SSAFY PT면접 IT 시사 학습자료 — 루트 인덱스

이 자료는 SSAFY(삼성 청년 SW·AI 아카데미) PT면접(발표면접)을 대비하기 위한 IT 시사 학습 모음입니다. 16개 핵심 주제를 다루며, 각 주제 디렉토리에는 6년치(2021~2026) 연도별 뉴스·사건 정리 파일과, 이를 종합한 메인 공부자료 `STUDY.md`가 들어 있습니다. 사용법은 다음과 같습니다. (1) 아래 표에서 관심 주제의 `STUDY.md`로 진입해 핵심 개념과 연도별 흐름을 파악합니다. (2) 발표 주제를 골라야 할 때는 각 STUDY.md의 "PT 발표 주제 추천"과 연도 파일의 "PT 발표 주제 후보"를 참고합니다. (3) 꼬리질문 대비는 각 문서의 "모범답안집/예상 질문 + 모범답안"으로 연습합니다. 모든 연도 파일은 실제 뉴스·공식 발표 출처를 근거로 작성되어 있어, 발표 중 근거로 인용할 수 있습니다.

## 면접 활용 가이드

### 준비 순서 (개념설명 → 뉴스 → 발표주제 → 모범답안)
1. **개념설명**: 먼저 주제 `STUDY.md`의 "핵심 개념 사전"으로 빈출 용어를 정의·원리·의의 수준까지 익힙니다. 비전공 면접관도 이해할 수 있게 직접 설명하는 연습을 합니다.
2. **뉴스**: 해당 주제의 연도 파일(특히 최근인 `2025.md`·`2026.md`)에서 대표 뉴스·사건과 시장 수치를 확인해, 발표에 쓸 근거를 확보합니다.
3. **발표주제**: STUDY.md의 "PT 발표 주제 추천"과 연도 파일의 "PT 발표 주제 후보"에서 주제를 골라, "문제 → 근거 → 제언"의 3단 구조로 발표 흐름을 구성합니다.
4. **모범답안**: 끝으로 STUDY.md의 "모범답안집"과 연도 파일의 "예상 질문 + 모범답안"으로 꼬리질문에 대비합니다. 지원자 본인의 경험(컨테이너 보안, 시스템콜 동적 관측 기반 이상탐지, Linux 커널 이해)을 답변에 자연스럽게 연계하면 차별화됩니다.

### 빈출 주제 추천
- **반드시 준비**: `genai`(생성형 AI·LLM), `agent`(AI 에이전트), `semiconductor`(반도체·HBM·AI 인프라) — 최근 PT면접에서 가장 자주 등장하는 핵심 축입니다.
- **지원동기 연계**: `korea_it`(한국 IT·삼성)는 삼성 계열 교육인 SSAFY 특성상 지원동기·포부 질문과 직접 연결됩니다.
- **본인 강점 연계**: `security`(제로트러스트·랜섬웨어), `cloud`(쿠버네티스·DevOps)는 컨테이너 보안·시스템콜 이상탐지·커널 경험을 발표와 답변에서 강하게 어필할 수 있는 주제입니다.
- **차별화 주제**: `physical_ai`(온디바이스·임베디드 AI), `robotics`(휴머노이드), `ai_governance`(AI 규제·윤리)는 최신 화제이면서 지원자 풀이 비교적 얕아 인상적인 발표를 만들기 좋습니다.
