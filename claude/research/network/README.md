# 네트워크 · 엣지 · 6G (slug: `network`)

SSAFY PT면접 대비 IT 시사 자료. 5G 상용화에서 6G 표준화까지, 오픈랜(O-RAN)·엣지 컴퓨팅·위성통신(스타링크)·AI-RAN·망 사용료 흐름을 연도별로 정리한다.

## 연도별 자료
- [2021](./2021.md) — 망 사용료 소송 점화(넷플릭스-SKB 1심), 엣지의 3GPP 표준 편입(Rel-17), 스타링크 베타 확산, 6G 선행연구
- [2022](./2022.md) — 스타링크 우크라이나 실전 투입, 5G 28GHz 주파수 회수(첫 사례), ITU 6G 2030 일정 합의, 이음5G 제도화
- [2023](./2023.md) — ITU IMT-2030(6G 비전 권고안), 넷플릭스-SKB 합의 종결, 위성 Direct to Cell, AI-RAN 개념 등장
- [2024](./2024.md) — 3GPP Rel-19·6G 착수, AI-RAN 얼라이언스 출범, 스타링크 D2C FCC 상용 승인·가입자 400만, 한국 하이퍼 AI 네트워크 전략
- [2025](./2025.md) — 인천 3GPP 6G 워크숍·Rel-20 6G 스터디, KT·삼성 AI-RAN 상용망 검증, NVIDIA-노키아 10억 달러, 스타링크 한국 상용 출시
- [2026](./2026.md) — MWC 2026 통신3사 'AI 기업' 선언·AINA 출범, SKT-에릭슨 6G MoU, 스타링크 1,000만·22개국 D2C, Rel-21 6G 타임라인 확정

## 핵심 흐름 요약
- 표준: 5G(NSA→SA) → 5G-Advanced(Rel-18/19) → 6G(IMT-2030, Rel-21, 2030 상용 목표)
- 인프라: 중앙집중 → 엣지/MEC → AI-RAN(통신+AI 연산 융합) → AI 네이티브 네트워크
- 위성: 스타링크 베타 → 우크라이나 실전 → Direct to Cell 상용 → 한국 진출·1,000만 가입자
- 정책: 망 사용료 소송 → 합의 → 국가 AI 네트워크 전략 → AINA(AI 네트워크 얼라이언스)

## 지원자 배경 연계 포인트
컨테이너 보안·시스템콜 동적 관측 기반 이상탐지·Linux 커널 이해를 다음 주제에 연결해 답변한다(과장 없이):
- vRAN/AI-RAN 컨테이너 워크로드 격리·런타임 관측 → 시스템콜 기반 이상탐지
- 엣지 노드 자원 격리(cgroup·네임스페이스)·실시간 관측(eBPF) → 커널 배경
- 위성/AI 네이티브 네트워크의 신뢰 경계·제로트러스트 → 인증·정책 무결성 보장
