# AI 에이전트 · 에이전틱 AI (slug: `agent`)

SSAFY PT면접 대비 IT 시사 자료. 연도별로 "그해 AI 에이전트 동향 + 발표·꼬리질문 준비자료"를 정리한다.
모든 연도 문서는 실제 뉴스·공식 발표를 근거로 작성했고, §2 각 항목과 §8에 출처 링크를 명시했다.

- [2026.md](./2026.md) — (1~6월) 과대광고에서 프로덕션으로, 거버넌스·격리 실행·Meta의 Manus 인수

## 큰 흐름 (한눈에)
- 자동화 주체의 진화: 규칙 기반 RPA(2021) → 추론-행동 LLM(2022~2023) → 컴퓨터를 직접 조작하는 에이전트(2024~2025) → 거버넌스로 통제되는 운영 에이전트(2026).
- 표준의 정착: 도구 호출(Function Calling, 2023) → 도구 연결 표준 MCP(2024) → 에이전트 간 통신 표준 A2A(2025) → 격리 실행·사설 MCP(2026).
- 일관된 리스크 축: 프롬프트 인젝션, 권한 위임, 비가역 작업, 도구 호출 감사 — 매년 반복·심화된다.

## 면접 활용 팁
- 발표 주제는 각 연도 §6에서 고르고, §7의 꼬리질문 답변에 지원자 배경(컨테이너 보안·시스템콜 동적 관측 기반 이상탐지·Linux 커널 이해, 풀스택·코딩테스트 확장 의지)을 연결한다.
- 수치는 §4 참고. 전망·추정치는 본문에 "전망/추정"으로 표기했으니 단정하지 말 것.
- 출처는 §8 목록 사용. 인용 시 매체·날짜를 함께 말하면 신뢰도가 올라간다.
