## AI 에이전트 · 에이전틱 AI (slug: `agent`)

SSAFY PT면접 대비 IT 시사 학습자료. "AI 에이전트 · 에이전틱 AI" 주제의 연도별 자료(2021~2026)와 6년치를 종합한 메인 학습문서 인덱스다. 사용자가 목표만 주면 스스로 계획·도구 사용·실행을 반복하는 자율 AI의 흐름을 다룬다. 모든 연도 문서는 실제 뉴스·공식 발표를 근거로 작성했고 출처 링크를 명시했다.

## 메인 학습문서
- [STUDY.md](./STUDY.md) — 6년치 종합 공부자료. 핵심 개념 사전(ReAct·MCP·A2A·Computer Use·프롬프트 인젝션 등), 연도별 흐름, PT 발표 주제 5개, 모범답안 11개, 지원자 경험 연계 포인트, 빠른 암기 카드 수록.

## 연도별 인덱스
- [2021.md](./2021.md) — WebGPT·Codex·DeepMind XLand가 에이전트 3대 요소의 원형을 제시. RPA(UiPath IPO)의 정점이자 규칙 기반 자동화 한계가 드러난 해.
- [2022.md](./2022.md) — ReAct 패턴·LangChain·MRKL로 설계 원형과 프레임워크가 갖춰지고, ChatGPT 출시가 자율 에이전트 폭발의 마지막 전제를 완성한 해.
- [2023.md](./2023.md) — GPT-4 위에서 AutoGPT·BabyAGI가 폭발했으나 무한루프·비용·검증 한계로 회의론도 부상. Function Calling이 실용화의 다리를 놓은 해.
- [2024.md](./2024.md) — 상용화 원년. Devin·Computer Use·MCP·Agentforce·Copilot Studio 등장, 간접 프롬프트 인젝션이 공식 위협으로 부각된 해.
- [2025.md](./2025.md) — '에이전트의 해'. Operator·ChatGPT agent·Manus 대중화, MCP·A2A 표준 확립, GitHub MCP·Perplexity Comet 보안 사고로 위협이 현실화된 해.
- [2026.md](./2026.md) — (1~6월) 과대광고에서 운영 현실로 전환. Managed Agents·병렬 서브에이전트, Antigravity 샌드박스 탈출(RCE) 패치, Meta의 Manus 인수로 빅테크 경쟁이 심화된 해.

## 연도별 한 줄 요약
| 연도 | 핵심 키워드 | 한 줄 |
|------|-------------|-------|

| 2022 | ReAct, LangChain, ChatGPT | 추론-행동 루프와 에이전트 프레임워크의 기반 마련 |
| 2023 | AutoGPT, Function Calling | 자율 에이전트 폭발과 도구 호출의 상용 표준화 |
| 2024 | MCP, Computer Use, Agentforce | 표준화·컴퓨터 조작·기업용 에이전트의 상용화 |
| 2025 | Operator, A2A, Manus | 소비자용 자율 에이전트와 에이전트 간 통신 표준 |
| 2026 | 거버넌스, Managed Agents | 프로덕션·보안·비용 중심으로의 현실화 |

## 큰 흐름 (한눈에)
- 자동화 주체의 진화: 규칙 기반 RPA(2021) → 추론-행동 LLM(2022~2023) → 컴퓨터를 직접 조작하는 에이전트(2024~2025) → 거버넌스로 통제되는 운영 에이전트(2026).
- 표준의 정착: 도구 호출(Function Calling, 2023) → 도구 연결 표준 MCP(2024) → 에이전트 간 통신 표준 A2A(2025) → 격리 실행·사설 MCP·MCP×A2A 2층 표준(2026).
- 일관된 리스크 축: 프롬프트 인젝션, 권한 위임, 비가역 작업, 도구 호출 감사 — 매년 반복·심화된다.
