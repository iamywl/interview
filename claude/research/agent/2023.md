## 2023 · AI 에이전트 · 에이전틱 AI

### 1. 그해 핵심 트렌드
- "자율 에이전트(autonomous agent)"가 폭발적으로 등장한 원년이다. GPT-4를 기반으로 목표만 주면 스스로 하위 작업을 나눠 실행하는 AutoGPT·BabyAGI가 오픈소스로 확산됐다.
- OpenAI가 ChatGPT 플러그인(3월)과 함수 호출(Function Calling, 6월)을 출시하며 LLM의 도구 사용을 표준 API로 제공했다. 에이전트가 외부 시스템을 호출하는 공식 통로가 마련됐다.
- 언어모델이 스스로 도구 사용법을 학습하는 연구(Meta Toolformer)가 발표됐다.
- 에이전트를 사회 시뮬레이션에 적용한 Stanford "Generative Agents(Smallville)"가 기억·반성·계획을 갖춘 에이전트 아키텍처를 제시했다.
- 다만 AutoGPT류는 무한 루프·비용 폭증·신뢰성 부족으로 "실용성보다 과장"이라는 비판도 동시에 받았다.

### 2. 대표 뉴스·사건
- Meta, 2023년 2월 9일 Toolformer 논문 공개. 언어모델이 계산기·검색·번역 등 API를 언제·어떻게 호출할지 자기지도학습으로 스스로 학습하게 했다. ([arXiv, 2023-02-09](https://arxiv.org/abs/2302.04761))
- OpenAI, 2023년 3월 ChatGPT 플러그인 출시. Expedia·Instacart·Zapier 등과 함께 ChatGPT가 외부 서비스·최신 정보에 접근하는 플랫폼으로 확장됐다. ([VentureBeat, 2023-03](https://venturebeat.com/ai/openai-turns-chatgpt-into-a-platform-overnight-with-addition-of-plugins))
- AutoGPT 공개(2023-03-30, Toran Bruce Richards). GPT-4로 목표를 자율 수행하는 오픈소스 에이전트로, 13일 만에 GitHub 스타 3만 개, 이후 10만 개를 돌파해 당시 최고속 성장 오픈소스 프로젝트가 됐다. ([Wikipedia - AutoGPT](https://en.wikipedia.org/wiki/AutoGPT))
- BabyAGI 공개(2023년 3월, Yohei Nakajima). 목표를 받아 작업 생성·실행·우선순위 재정렬을 반복하는 루프와 벡터 메모리를 결합한 최초의 공개 자율 에이전트 중 하나다. ([GitHub - babyagi](https://github.com/yoheinakajima/babyagi))
- OpenAI, 2023년 6월 Function Calling 출시. GPT-4·GPT-3.5에 함수 정의를 주면 JSON 인자를 생성해 외부 도구를 호출하게 했다. 플러그인의 기반 메커니즘을 API로 일반화했다. ([OpenAI, 2023-06](https://openai.com/index/function-calling-and-other-api-updates/))
- Stanford, 2023년 4월 Generative Agents(Smallville) 공개. 25개 에이전트가 기억·반성·계획을 갖고 사회적 상호작용을 자율 수행하는 시뮬레이션으로, 사람보다 믿을 만하다는 평가를 받았다. ([arXiv, 2023-04-07](https://arxiv.org/abs/2304.03442))

### 3. 핵심 기업·제품·기술 키워드
- 기업·프로젝트: OpenAI(플러그인·Function Calling), Meta(Toolformer), AutoGPT, BabyAGI, AgentGPT, Stanford(Generative Agents), LangChain
- 기술: 자율 작업 분해, 함수 호출(JSON tool-use), 벡터 메모리, 기억-반성-계획 아키텍처
- 개념: 목표 지향 자율 루프, 도구 호출 표준화

### 4. 시장 수치·전망 (전망/추정)
- AutoGPT는 공개 13일 만에 GitHub 스타 3만 개, 이후 10만 개 돌파 — 에이전트에 대한 개발자 수요 급증의 정량 지표. ([Wikipedia - AutoGPT](https://en.wikipedia.org/wiki/AutoGPT))
- Toolformer: GPT-J(67억 파라미터)가 도구 사용만으로 GPT-3(1,750억)를 일부 과제에서 능가 — 도구 결합의 효율 가치를 시사(추정). ([arXiv, 2023-02-09](https://arxiv.org/abs/2302.04761))
- 2023년에는 에이전트 전용 시장 규모 공식 집계는 미성숙했고, 대부분 생성형 AI 시장으로 포괄됐다.

### 5. 전년 대비 변화점
- 새로 뜬 것: 자율 에이전트(AutoGPT·BabyAGI), 함수 호출 표준 API, 기억 기반 에이전트 아키텍처.
- 강해진 것: 도구 사용이 연구(ReAct·Toolformer)에서 상용 API(Function Calling)로 내려왔다.
- 식기 시작한 것: 초기 자율 에이전트의 과장. 무한 루프·비용·신뢰성 문제로 "데모는 화려하나 실무 적용은 이르다"는 회의론이 함께 부상했다.

### 6. PT 발표 주제 후보
1. "AutoGPT 신드롬" — 목표만 주면 스스로 일하는 에이전트의 폭발과, 그 한계(비용·신뢰성)를 균형 있게 본다.
2. "Function Calling이 만든 표준" — LLM 도구 호출이 연구에서 상용 API로 내려온 2023년이 에이전트 실용화의 전환점이다.
3. "기억하는 에이전트" — Stanford Generative Agents의 기억-반성-계획 구조가 단발성 챗봇을 넘어선 자율성의 핵심임을 보인다.

### 7. 예상 꼬리질문 + 답변 포인트
1. Q: AutoGPT가 실무에 바로 못 쓰인 이유는?
   - A: 자율 루프가 목표를 잃고 반복하거나 토큰 비용이 폭증하고, 도구 실행 결과를 검증하지 못해 오류가 누적됐기 때문입니다. 저는 시스템콜 관측 기반 이상탐지에서 행동 시퀀스의 정상/비정상 경계를 다뤄봤는데, 에이전트의 행동 검증·중단 조건 설계도 같은 관측·판단 문제라고 봅니다.
2. Q: Function Calling의 보안 위험은?
   - A: 에이전트가 외부 함수를 실행하므로 프롬프트 인젝션으로 의도하지 않은 함수가 호출되거나 인자가 조작될 수 있습니다. 저는 컨테이너 격리와 런타임 권한 최소화에 익숙해, 도구 호출을 최소 권한·감사 로깅과 함께 설계하는 데 관심이 있습니다.
3. Q: 자율 에이전트의 무한 루프를 어떻게 막나?
   - A: 단계 수·비용 상한, 도구 호출 화이트리스트, 결과 검증 게이트가 기본입니다. 저는 커널 수준에서 프로세스 행동을 관측한 경험이 있어, 에이전트 실행을 외부에서 모니터링하고 비정상 패턴에서 강제 종료하는 가드레일 설계에 흥미가 있습니다.
