## 2024 · AI 에이전트 · 에이전틱 AI

### 1. 그해 핵심 트렌드
- "에이전틱 AI(agentic AI)"가 업계 공식 용어로 자리잡았다. 데모 수준이던 자율 에이전트가 기업용 제품으로 상용화됐다.
- 표준화의 해다. Anthropic이 Model Context Protocol(MCP)을 개방형 표준으로 공개해, 에이전트와 외부 데이터·도구 연결의 "N×M" 통합 문제를 해결하는 공통 규격을 제시했다.
- "컴퓨터 사용(Computer Use)" 능력이 등장했다. Anthropic Claude가 화면을 보고 커서·클릭·타이핑으로 컴퓨터를 직접 조작하는 첫 프런티어 모델로 공개됐다.
- 빅테크가 에이전트 제품을 대거 출시했다. Salesforce Agentforce(기업 CRM 에이전트), Google Project Mariner·Gemini 2.0("에이전틱 네이티브" 모델·브라우저 에이전트)가 대표적이다.
- 보안 위협으로 프롬프트 인젝션이 본격적으로 부각됐다. 화면·웹 콘텐츠를 그대로 따르는 에이전트의 취약성이 공식 경고됐다.

### 2. 대표 뉴스·사건
- Anthropic, 2024년 10월 22일 "컴퓨터 사용(Computer Use)"을 Claude 3.5 Sonnet에 공개 베타로 도입. 화면 스크린샷을 보고 픽셀 좌표를 계산해 커서 이동·클릭·타이핑을 수행하는 첫 프런티어 모델이다. ([Anthropic, 2024-10-22](https://www.anthropic.com/news/3-5-models-and-computer-use))
- Salesforce, 2024년 10월 29일 Agentforce 정식 출시(GA). Atlas Reasoning Engine 기반으로 CRM·서드파티 시스템에서 자율적으로 작업을 수행하는 기업용 에이전트 계층을 제공한다. ([Salesforce, 2024-10-29](https://www.salesforce.com/news/press-releases/2024/10/29/agentforce-general-availability-announcement/))
- Anthropic, 2024년 11월 25일 Model Context Protocol(MCP) 오픈소스 공개. AI 어시스턴트와 데이터·도구를 연결하는 개방형 표준으로, Google Drive·Slack·GitHub·Postgres 등 사전 구축 서버를 함께 제공했다. ([Anthropic, 2024-11-25](https://www.anthropic.com/news/model-context-protocol))
- Google DeepMind, 2024년 12월 11일 Gemini 2.0와 Project Mariner 공개. "에이전틱 네이티브" 모델과 브라우저를 자율 조작하는 Chrome 확장 에이전트로, WebVoyager 벤치마크에서 83.5% 최고 성능을 기록했다. ([Google, 2024-12-11](https://blog.google/technology/google-deepmind/google-gemini-ai-update-december-2024/))
- Salesforce, Dreamforce 2024에서 고객이 10,000개 이상의 자율 에이전트를 제작. 에이전트 프로토타입을 수 분 만에 생성하는 사례로 기업 채택 가속을 보여줬다. ([Salesforce - Dreamforce](https://www.salesforce.com/news/stories/agentforce-launch-zone-announcement/))

### 3. 핵심 기업·제품·기술 키워드
- 기업·제품: Anthropic(Computer Use·MCP), Salesforce(Agentforce·Atlas Reasoning Engine), Google(Gemini 2.0·Project Mariner)
- 기술: Model Context Protocol(JSON-RPC 기반), 컴퓨터 사용(GUI 조작), 에이전틱 네이티브 모델, 추론 엔진
- 개념: N×M 통합 문제 해결, 프롬프트 인젝션 위협, 인간-에이전트 상호작용

### 4. 시장 수치·전망 (전망/추정)
- Project Mariner, WebVoyager 벤치마크에서 단일 에이전트 83.5% 달성 — 실제 웹 작업 자동화 성능의 정량 지표. ([Google, 2024-12-11](https://blog.google/technology/google-deepmind/google-gemini-ai-update-december-2024/))
- Agentforce 에이전트, Fortune 500 고객 벤치마크에서 정확도 약 1/3 향상·관련성 2배라고 발표(추정·자체 발표치). ([Salesforce, 2024-10-29](https://www.salesforce.com/news/press-releases/2024/10/29/agentforce-general-availability-announcement/))
- Gartner 등은 2028년까지 일상 업무 의사결정의 약 15%가 에이전트에 의해 자율적으로 이뤄질 것으로 전망(전망). ([VentureBeat - RPA to AI agents](https://venturebeat.com/ai/weve-come-a-long-way-from-rpa-how-ai-agents-are-revolutionizing-automation))

### 5. 전년 대비 변화점
- 새로 뜬 것: MCP 표준, 컴퓨터 사용(GUI 직접 조작), 기업용 에이전트 플랫폼(Agentforce), 에이전틱 네이티브 모델(Gemini 2.0).
- 강해진 것: 2023년의 실험적 자율 에이전트가 2024년 상용 제품·표준 규격으로 성숙했다.
- 식은 것: AutoGPT식 "단일 만능 자율 봇" 환상은 줄고, 도구 연결 표준·기업 워크플로 통합이라는 실용 방향으로 이동했다.

### 6. PT 발표 주제 후보
1. "MCP: 에이전트의 USB-C" — 모델과 도구 연결의 N×M 문제를 표준으로 푼 MCP가 에이전트 생태계의 기반이 됐다.
2. "컴퓨터를 쓰는 AI" — Claude Computer Use·Project Mariner가 화면을 직접 조작하는 단계로 진입하며 자동화 범위가 GUI 전체로 확장됐다.
3. "에이전트, 기업 안으로" — Agentforce가 보여준 CRM 통합형 에이전트로 자율 AI가 데모에서 매출 도구로 전환됐다.

### 7. 예상 꼬리질문 + 답변 포인트
1. Q: MCP가 왜 중요한가?
   - A: 모델마다·도구마다 커넥터를 따로 만들던 N×M 문제를 JSON-RPC 기반 공통 규격으로 표준화한 것이 핵심입니다. 저는 시스템콜·커널 인터페이스 같은 표준 계층을 다뤄봐서, 표준 프로토콜이 생태계 확장과 동시에 보안 감사 지점을 한 곳으로 모으는 효과가 있다는 점에 주목합니다.
2. Q: Computer Use의 보안 위험은?
   - A: Anthropic도 프롬프트 인젝션을 명시적으로 경고했습니다. 화면·웹 콘텐츠에 숨은 지시를 에이전트가 따를 수 있습니다. 저는 컨테이너 격리와 런타임 시스템콜 관측 경험이 있어, GUI 조작 에이전트를 격리된 가상 데스크톱에서 실행하고 행동을 감사하는 방어에 관심이 있습니다.
3. Q: 기업이 에이전트를 도입할 때 가장 큰 장벽은?
   - A: 신뢰성과 권한 통제입니다. 에이전트가 실제 시스템에 쓰기 작업을 하므로 잘못된 행동의 비용이 큽니다. 저는 이상탐지를 다뤄봐서, 에이전트 행동을 정상 범위와 비교해 위험 행위를 차단하는 가드레일이 도입의 전제라고 봅니다.
